UMC接口对接需求清单
===========

平台通过本地 UMC 连接设备、执行命令并获取原始日志，通过服务端 UMC 分析日志、获取报告数据和报告文件。

**共需4个接口。命令执行和日志分析同步返回结果，文件单独下载。** 接口不依赖设备纳管，不传入平台任务、工单、项目等业务标识。
一、接口清单

------

| 接口                    | 提供方        | 用途                             | 入参                                              | 返回数据                                                     |
| ----------------------- | ------------- | -------------------------------- | ------------------------------------------------- | ------------------------------------------------------------ |
| **1．连接设备执行命令** | 本地UMC       | 连接指定设备，执行命令并获取输出 | SSH连接信息：IP、端口、用户名、临时密码；命令列表 | 执行批次ID、设备SN（可获取时）、各命令执行状态及输出、原始日志文件标识 |
| **2．原始日志下载**     | 产生日志的UMC | 获取原始日志，供平台留存和归档   | 原始日志文件标识；<br /><br />SN                  | 原始日志文件、文件名<br /><br />SN对应的最新日志文件         |
| **3．日志分析**         | 服务端UMC     | 分析日志，生成检测结果和报告     | 日志数据或日志文件                                | 检测结果、问题明细、结构化报告数据、报告文件标识             |
| **4．报告下载**         | 服务端UMC     | 获取报告文档，供平台留存和归档   | 报告文件标识                                      | 报告文件、文件名、格式及版本                                 |

其中：

* **问题明细**包含设备SN、检测项、检测结论、问题描述、严重级别及处理建议。
* **报告数据**包含设备信息、巡检概览、检测明细、问题清单及实际使用的规则版本。
* 临时SSH密码仅用于当次执行，不进入日志、报告或持久化业务记录。

二、在线调用图
-------

    ```mermaid
    sequenceDiagram
        participant P as 平台
        participant L as 本地UMC
        participant S as 服务端UMC
    
        P->>L: 1. 传入SSH连接信息和命令列表
        L-->>P: 同步返回执行结果、命令输出及日志文件标识
        P->>L: 2. 下载原始日志
        L-->>P: 原始日志文件
        P->>S: 3. 提交日志数据或日志文件分析
        S-->>P: 同步返回检测结果、问题明细、报告数据及文件标识
        P->>S: 4. 下载报告
        S-->>P: 报告文档
    ```

三、离线调用图
-------

    ```mermaid
    sequenceDiagram
        participant F as 现场
        participant P as 平台
        participant S as 服务端UMC
    
        F->>P: 提交现场取得的原始日志
        P->>S: 3. 提交日志分析
        S-->>P: 同步返回检测结果、问题明细、报告数据及文件标识
        P->>S: 4. 下载报告
        S-->>P: 报告文档
    ```

离线场景已取得原始日志文件时，直接调用接口3；需要从 UMC 获取原始日志时，先调用接口2。
