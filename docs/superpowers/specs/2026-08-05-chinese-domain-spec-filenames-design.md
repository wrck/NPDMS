# 领域需求规格中文文件名调整设计

## 1. 目标

将 13 份领域需求规格文件统一改为中文可读文件名，同时保留领域编码，便于业务人员识别并维持稳定的领域引用。

## 2. 命名规则

统一格式：

```text
领域编码-中文领域名称需求规格.md
```

示例：

- `IMP-现场实施需求规格.md`
- `AST-资产管理需求规格.md`
- `PROJ-项目治理需求规格.md`

## 4. 引用同步

同步修改以下内容中的领域文档路径：

- 领域生成器的目标文件名配置
- 全局校验器及自动化测试
- 规格 README
- 总体规格中的领域文档引用
- 需求迁移矩阵
- 验收追溯矩阵
- 验证报告及实施计划中的实际文件引用

旧英文文件名不保留副本，避免同一领域出现两个权威入口。Git 历史负责旧路径追溯。

## 5. 不变范围

- 不改变 13 领域名称、编码和 Owner 映射。
- 不改变 FR、BR、DR、AC 编号和需求内容。
- `FR-ENG-021 到货签收管理`仍唯一归属 `IMP 现场实施`。
- 领域文档继续使用已确认的原分卷五段式结构。

## 6. 验收标准

- `domains/` 下恰好存在 13 份符合新命名规则的领域需求规格。
- 不存在旧英文 `*-srs.md` 领域文件。
- 所有内部文档引用均指向存在的新中文文件名。
- 领域树校验、自动化测试和 `git diff --check` 通过。
