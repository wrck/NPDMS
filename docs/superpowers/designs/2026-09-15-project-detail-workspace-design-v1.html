设计说明（过程稿 · 不作为正式基线）

规格映射

  • F-PROJ-007 §6：项目概览固定「基本信息、项目树、团队成员、项目任务、设备清单、实施范围」六页签；Stage 为一级导航、任务树按需展开、右侧工作台按受信任绑定装载；窄屏抽屉/分段切换（本稿以折叠区示意）。
  • F-PROJ-008 §7：当前 Stage 区域展示冻结图解析目标、EXIT Gate 与有序 Reference；PROCESS/APPROVAL 未启动时对有权项目经理显示「发起审批」，运行中显示流程实例入口；仅 readiness 全部满足且有权时显示推进按钮；S4 只保留「进入验收阶段」专用入口。
  • PRD §3.1.8 / §4.2.9：四个控制点标注于轨上门禁（计划审批、方案审核、割接门禁、闭环审核）；阶段工作台含通用信息、前后置关系、准入准出、阶段交付件与 WorkBinding 执行区；阶段超期在轨道同步标红。
  • PM-02 / 规则14：项目树页签呈现主子项目父子树与整体进度；概览为独立项目级入口，不混入阶段导航。

视觉与实现约定

  • 视觉锚定宿主 Element Plus 主题（主色 #409eff、标准状态色、4px 圆角、无阴影描边面板，对应 ContentWrap shadow="never"），实现时使用主题变量，减少内联样式。
  • 签名元素唯一：阶段推进轨（节点 + 门禁菱形 + 超期红标）；其余区块保持克制，装饰性编号、全大写字距标签、图标堆砌均不使用；等宽字体仅用于真实编码（阶段码、任务码、流程 key）。
  • 组件映射：页签 el-tabs；描述列表 el-descriptions；导航树 el-tree；表格 el-table；门禁 Reference 列表可用 el-table 或自定义列表；readiness 摘要 el-alert / el-progress。
  • 权限标注：编辑项目、发起审批、推进按钮均受功能权限与数据范围约束；前端禁用态仅为引导，授权以服务端重验为准。
  • 响应式：≥1280 完整双栏；≤1024 左导航折叠为顶部滚动区（实现为抽屉/分段切换）；≤768 统计项换行、描述列表降列；阶段轨在窄屏内横向滚动，页面级无横向溢出。
