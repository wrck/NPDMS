设计说明（过程稿 · 不作为正式基线）

规格映射

  • F-PROJ-007 §6：项目概览承载「基本信息、项目树、团队成员、项目任务、设备清单、实施范围」六类内容；v10 起项目树以树形表格呈现在「项目树」页签内（仅在有主/子项目时显示）；项目基本信息为页签区上方固定区块；左侧导航栏仅保留「项目概览」入口与阶段任务（S0~S6 一级导航、任务树按需展开），点击导航项切换右侧内容；阶段为工作区（执行内容为主层级，窄屏以抽屉/分段切换，本稿以折叠区示意）。
  • F-PROJ-008 §7：门禁项与推进目标在右栏展示；审批未启动时对有权项目经理显示「发起审批」，审批中显示审批入口；门禁全部满足且有权时显示推进按钮；S4 只保留「进入验收阶段」专用入口。
  • PRD §3.1.8 / §4.2.9：四个控制点标注于轨上门禁（计划审批、方案审核、割接门禁、闭环审核）；工作区含执行区、阶段交付件与前后置/准入信息；阶段超期在轨道同步标红。
  • PM-02 / 规则14：项目树以概览「项目树」页签的树形表格呈现主子项目父子层级与各项目状态/进度；左侧导航栏承载概览/阶段切换，与项目树分工明确。

视觉与实现约定

  • 视觉锚定宿主 Element Plus 主题（主色 #409eff、标准状态色、4px 圆角、无阴影描边面板，对应 ContentWrap shadow="never"），实现时使用主题变量，减少内联样式。
  • 签名元素唯一：阶段推进轨（节点 + 门禁菱形 + 超期红标）；其余区块保持克制，装饰性编号、全大写字距标签、图标堆砌均不使用；等宽字体仅用于真实编码（阶段码、任务码、流程 key）。
  • 组件映射：页签 el-tabs；描述列表 el-descriptions；概览「项目树」页签为 el-table 树形表格、阶段任务导航树 el-tree；表格 el-table；门禁右栏用紧凑列表 + el-progress；执行区 el-descriptions + 按钮组。
  • v2 层级约定：顶部身份卡压缩为两行、统计内联；执行区为工作区第一层级，阶段交付件与阶段信息为辅助层级；门禁与阶段历史仅在大屏（≥1280）固定右栏并吸顶，其余宽度回流至工作区下方。
  • v4 项目概览改版：项目树移出页签、常驻概览左栏（有主/子项目时显示，节点与整栏均可折叠，点击节点示意快捷切换），右侧上部为项目基本信息、下部为关联信息页签；无项目树时左栏不显示。
  • v5 统一左侧导航：项目概览与阶段任务合并为同一左侧导航栏（项目树 → 项目概览 → 阶段任务），顶部模式切换与工作区内嵌阶段导航取消，右侧统一为内容区（概览／工作区两态）；项目树折叠由 v4 的整栏收缩改为段内收起/展开；阶段推进轨保留为阶段状态与门禁可视化。
  • v6 项目树回归概览：项目树从左侧导航栏移回项目概览内容区（恢复 v4 的概览内左树右信息与整栏折叠），左侧导航栏仅保留「项目概览」与「阶段任务」两段；工作区双栏与阶段推进轨维持 v5 结构。
  • v7 图例收纳：阶段轨下方常驻图例移除，改为「?」提示图标按需悬浮展示——悬停 / 键盘聚焦 / 点击均可唤出，点击页面其他位置收起（对应 EP el-tooltip 惯例：悬浮层带浅投影，静态面板仍无阴影）；轨下仅保留推进规则提示一行，颜色含义与图例项不变。
  • v8 项目树回归页签：项目树从概览左栏移回「项目树」页签（关联信息页签首位，有主/子项目时显示，节点可折叠、点击示意快捷切换），概览恢复为「基本信息固定区块 + 关联信息页签」单列结构；左侧导航栏维持「项目概览 / 阶段任务」两段，阶段推进轨与图例悬浮提示维持 v7 结构。
  • v9 轨脚折叠项：推进规则提示与状态/门禁图例合并为「推进说明与图例」折叠项，默认折叠仅占一行、点击展开/收起（v7 的「?」悬浮图例取消）；对应 EP el-collapse 惯例，展开时在轨下顺排、不遮挡轨道内容。
  • v10 项目树恢复树形表格：「项目树」页签内容由节点树改回树形表格（项目／状态／当前阶段／进度／项目经理／计划周期，├└ 缩进示意父子层级，对应 el-table 树形表格），节点级快捷切换交互随之移除，页签显隐仍由项目父子关系驱动。
  • v11 折叠项上轨：「推进说明与图例」折叠项从轨脚独立行移至阶段轨行末、与轨道同行，默认折叠时轨下零占用；展开时说明与图例在轨下顺排；窄屏下折叠项位于横向滚动轨末端，滚动轨道可见。
  • v3 阶段轨单行化：节点与阶段名同行，去每阶段日期区间与「xx 完成」标记（阶段日期细节由概览任务页签与工作区头部承载），保留门禁菱形、四个控制点标签、超期红标与图例；轨高由 185px 收窄至 93px（1440 宽实测）。
  • 版本留存：本目录过程稿每轮修订前快照为独立文件（如 *-v2.html），主文件恒为最新版，便于逐版对比；首轮 v1 修订时未及快照，原文件已不可恢复，现存 *-v1.html 为事后重建稿（重建块在文内标注，非原始文件）。
  • 面向实施人员表达：门禁项以「任务 / 里程碑 / 交付件 / 审批」中文类型呈现；状态机、幂等键、锁定重验、快照编号等内部校验细节不外显，仅保留执行者需要的结论（如「完成剩余 4 项后即可推进」）。
  • 权限标注：编辑项目、发起审批、推进按钮均受功能权限与数据范围约束；前端禁用态仅为引导，授权以服务端校验为准。
  • 响应式：≥1280 左侧导航 280px + 内容区（概览／工作区两态），概览为基本信息固定区块 + 关联信息页签单列，工作区为双栏（执行工作区｜门禁·历史侧栏）；≤1280 导航收窄 240px、工作区右栏回流至下方；≤1024 左侧导航并入内容区上方（限高滚动）；≤768 统计内联换行、描述列表降列；阶段轨窄屏横向滚动，页面级无横向溢出。
  • 项目概览顶部「布局示意」开关（有主/子项目 / 无项目树）为过程稿演示装置，用于预览「项目树」页签的显示与隐藏；实现中由项目父子关系数据驱动，不作为页面功能。

【待确认】与示例数据边界

  • 设备清单、实施范围两页签的字段与状态值域未在已读规格中定义，本稿为占位结构，以对应 Feature Spec 为准。
  • 门禁项的排序与文案以接口返回为准；示例数据（项目、人员、编码、日期）仅作演示，不代表真实数据。
  • 非原生 WorkBinding 的失败关闭展示、租户扩展任务状态的展示样式，留待对应 Feature 落地时补充。
