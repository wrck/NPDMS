## 2. 变更范围

| 项目 | 修订013结果 |
|---|---|
| 权限Owner | 复用System现有`PermissionApi.hasAnyPermissions`，不新增接口、DTO、Mapper或表 |
| 租户访问 | `skipPermissionCheck`只服务上下文切换；审核必须在目标租户上下文重新调用`PermissionApi` |
| 允许主体 | 目标租户普通角色—菜单授权用户与System超级管理员均按现有布尔语义允许 |
| 失败语义 | 无认证用户、无目标租户、返回`false`或System异常时失败关闭，不追加审核事实 |
| 审计字段 | 保存tenant、审核人、精确权限码和`RBAC_PERMISSION`；`authorizationSourceId`为空，不伪造授权路径 |
| 正式范围 | Requirement数量、目标版本切片、优先级、领域Owner、角色、规则状态与API动作均不变 |
