## 2. 变更范围

| 项目 | 修订011结果 |
|---|---|
| 命令超时 | 默认30秒，只允许配置1～30秒 |
| 产品类型 | Inspection只消费AST公开契约并冻结编码/名称快照，不维护第二套目录 |
| 正则安全 | JDK 25受限语法子集及明确复杂度预算；发布前扫描秘密模式 |
| 规则身份 | 规则名称属于租户内永久唯一稳定身份，停用、软删除和新revision不释放 |
| 草稿/发布 | 稳定身份字段创建时必填；草稿其余字段可不完整，发布必须全量完整 |
| 阈值/审核 | 阈值类型固定`NUMBER`；审核结论只允许`PASSED/REJECTED`并绑定当前摘要 |
| 正式范围 | Requirement数量、目标版本切片、优先级和领域Owner均不变 |
