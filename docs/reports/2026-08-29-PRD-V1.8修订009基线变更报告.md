## 2. 范围与影响

| 项目 | 修订009结果 |
|---|---|
| 权威触发 | 项目进入其设定的验收阶段 |
| 首次绑定范围 | 该项目当时全部当前有效DeliveryScope分配版本 |

| 事实先后 | 项目阶段进入先触发范围绑定；进入时不要求创建或补齐初验/终验单 |
| 报告完备 | 初验或终验活动申请标记完成时，对应报告须具备验收时间、结论、验收人和附件的当前有效版本 |

| 首次可见性 | 合同目录、详情、订单、订单行和关系维护均命中当前公司范围；部门不推导或扩大公司范围 |

| 撤权、到期与版本 | 写前重新校验并记录授权事实稳定ID/版本；撤权或到期禁止后续访问，不删除既有业务历史 |
| 商务敏感字段 | 公司范围不授予字段明文权限；未通过独立字段权限时脱敏或不返回 |
| 原子结果 | 任一范围锁定、版本校验或绑定失败时，阶段进入或范围生效整体不成功，不留部分绑定 |
