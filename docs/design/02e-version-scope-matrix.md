# SDS Phase 1：版本范围矩阵

> 文档状态：`BASELINE`
> 适用基线：PRD V1.8 修订007（`docs/baseline/prd-v1.8.md`）
> Requirement ID：PRD V1.8 附录 A.1 的100项正式Requirement及附录A.1.1派生的111个目标版本切片
> Owner：SDS Phase 1 架构设计；修订007差量复核已完成
> 适用规则：本矩阵只收录已批准的版本结果和边界；正文明确延后、V3或OUT_OF_SCOPE的内容不前置


| 能力 | V1 | V2 | V3/排除 |
|---|---|---|---|
| 服务经理指派（PM-08） | 区域—部门映射配置、候选过滤与人工指派 | 冻结规则唯一匹配时自动形成并生效主责指派；无匹配或多匹配保持待指派并回到V1人工流程 | 不增加未定义的智能分配 |
| Stage—ProjectTask工作台（PM-11） | 层级模型、WorkBinding配置、基础查询和六类绑定统一工作台 | 甘特展示及受控依赖新增、更新、删除 | 不含其他未定义高级编排；不建立第二套任务事实 |
| 到货、安装、配置Log、业务联调、实施证据上传 | 建设 | — | — |
| 实施质量检查 | — | IMP-01 | — |
| 现场安全检查 | — | — | IMP-02已退出当前正式范围；恢复时须重新立项 |
| 培训记录与确认（ACC-01） | 培训记录、链接/扫码与客户确认 | 短信/邮件和钉钉自动推送；送达不等于确认，失败回退V1链接/扫码 | — |
| 满意度收集（ACC-02） | 问卷、评分、整改重收、导出和签字闭环 | 短信/邮件和钉钉自动触达 | 异常放行复核仅作后续演进方向 |
| 割接任务（CUT-01） | P1～P6任务闭环 | 按授权范围展示割接首页KPI，不改变任务状态和P1～P6流程 | 自动建议等级仅作V3演进方向 |
| 割接P3清单（CUT-03） | 动态清单生成、填写、暂存、提交和基础流程跳转 | 授权清单导出与流程跳转配置优化 | 不建立独立采集阶段、逐步骤执行或稳定观察 |
| 割接分级审批（CUT-05） | 分级审批 | A/B级专项提前时间判断及经定义的外部提醒；短信/邮件复用INT-10、钉钉复用INT-05 | 不新增平台通用SLA或通用IM渠道 |
| 割接配置基础（CUT-07、CUT-09、CUT-10） | 动态模板、表单和匹配的首批配置基础，先于或不晚于首个消费能力交付 | — | 删除未定义的V2效率增强，不虚构V3承诺 |
| ITR版本与割接协作（INT-02） | 同步设备版本并接收割接任务 | 接收ITR故障来源并回传ITR来源CUT归档结果；出向失败不回滚本地归档 | 技术公告不归INT-02 |
| 技术公告治理（INT-04） | — | ITR技术公告基础同步，且为公告唯一Owner | KNO-V3-01～08治理增强 |
| 钉钉/HR/OA协作（INT-05） | 钉钉/HR核心协作 | OA领料/外采流程及转包待办链接协作；外部系统不拥有平台审批与业务状态 | — |
| Device Access & Collection（INT-12） | 实施、割接复用统一设备连接、凭证、任务与采集能力 | 在线巡检复用同一契约 | 不重复建设凭证、任务或采集执行引擎 |
| 在线巡检命令超时（NFR-02） | 设备凭证与采集安全基线 | 当前命令终止并失败；后续命令按冻结的已发布规则决定并留痕 | — |
| 项目状态分层 | `current_stage` S0～S6、`lifecycle_status` ACTIVE；PM-10异常关闭和受控重开、CLO-02正常闭环 | — | 不新增维护阶段；`display_status`只读派生 |
| 实施方案配置脚本 | SCH-01上传/引用脚本文件 | SCH-03脚本解析与版本治理增强 | SCH-03不构成EXE-03 V1前置 |
| 现有采集平台子应用集成 | 复用现有设备连接、命令执行和原始采集能力 | 扩展巡检调用和结果解释 | 不重复建设采集引擎 |
| 已明确后置项（EXE-05、CUT-06、INT-03） | 仅交付各自V1正式切片 | — | 自动识别/升级、多人协同填写、CRM治理工作台均为V3跨需求演进方向 |
| 通用工单、打卡、工时和割接保障工单 | — | — | WO-01～06、WO-08～10、RPT-01/04为P3候选；不恢复通用WorkOrder或迁入CUT |
| 续保经营、维保空间、独立维保档案 | — | — | OUT_OF_SCOPE |

本矩阵不新增版本承诺。配置能力遵循首个消费者前置原则，但正文明确为V2、V3或延后的内容保持原版本。
