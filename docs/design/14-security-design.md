# SDS Phase 3：安全设计

> 文档状态：`IN_REVIEW`
> 适用基线：PRD V1.8修订007及批准增量`CHG-PRD-2026-08-27-004`
> Requirement ID：NFR-01、NFR-02、INT-09、INT-12、PLT-02，以及全部100项正式Requirement、111个目标版本切片的认证、授权、数据隔离、文件、集成和审计安全
> Owner：SDS Phase 3安全架构；业务授权Owner继承07，凭证Owner继承Device Access & Collection
> 前置设计：07、10、12、13、15、16分册

## 1. 安全目标与不可变边界

1. 所有用户、服务、回调和后台任务先认证，再执行服务端授权；客户端隐藏按钮不构成安全边界。
2. 跨租户、未授权平级项目、越级设备/文件、已撤销授权请求的验收拒绝率必须为100%。
3. 设备密码、私钥、Token、完整授权码和认证头不进入页面响应、浏览器存储、数据库明文字段、缓存、消息、持久队列、日志、回调、异常堆栈或导出。
4. 已保存凭证使用AES-256或不低于同等强度的批准算法；密钥材料与业务数据分离，支持密钥版本、轮换和撤销。
5. 外部HTTP成功、通知送达、待办完成和消息ACK均不能绕过业务状态机、权限和门禁。
6. 安全控制不可由普通业务字典、租户配置或调试开关降低。`CHG-PRD-2026-08-27-004`批准的文件病毒扫描开关仅由部署Owner统一配置，不属于业务侧可调规则。

## 2. 资产、主体与信任边界

### 2.1 受保护资产

| 资产 | 风险 | 强制控制 |
|---|---|---|
| 项目、任务、合同、设备、客户数据 | 跨租户/跨项目泄露或篡改 | tenant + 功能权限 + DataScope + 聚合守卫；查询与写入均服务端过滤 |
| ProjectTask业务工作台与共享动态表单 | 通过绑定或模板配置加载未授权对象、高信任客户端代码或跨Context数据 | WorkBinding类型与执行器受控且服务端合并目标权限；业务实例先由Owner Provider校验范围/状态再进入PLT锁，未知失败关闭；F-PLT-002仅允许获权发布者发布明确修订中的客户端配置，目标API仍独立鉴权，PLT不执行服务端脚本、不代理URL、不允许仓储直连 |
| 设备凭证和临时密码 | 明文泄露、越权取用、重放 | 密钥分离、五元组授权、任务级短期取密、全链路秘密扫描 |
| 审批、状态、归属、交付证据 | 绕过门禁、否认操作或事后删除历史 | command/transition、不可变快照、操作审计、版本/幂等；业务事实、审批历史及明确留痕操作按ADR-0006永久不可删除 |
| 普通网络与安全运行日志 | 留存不足、冷归档篡改或到期清理误删永久审计 | 按ADR-0007在线180天、不可变冷存储185天；分类隔离、加密、完整性校验、恢复抽检及清理清单 |
| 调试日志 | 长期开启、记录秘密或无限延期形成影子数据仓库 | 按ADR-0010默认7天、专项最长30天；延期登记原因/负责人/到期时间，脱敏、秘密扫描和自动到期 |
| 文件和外部结果 | 恶意文件、越权下载、内容替换 | 文件身份+版本+哈希+扫描+业务实时权限 |
| 外部接口和回调 | 伪造、重放、乱序、SSRF | 服务身份、TLS、验签、来源白名单、幂等、顺序和出向目标注册 |
| 构建与迁移制品 | 依赖投毒、制品篡改、迁移漂移 | 锁文件、冻结安装、制品哈希、迁移校验和、releaseId和证据清单 |

### 2.2 信任区与允许数据流

```text
Browser
  -> HTTPS入口/反向代理
  -> Platform Backend (认证、授权、业务命令)
       -> MySQL / Redis / File Storage
       -> Message / Telemetry adapters
       -> External Integration ACLs
       -> DAC trusted secret broker
            -> Collection sub-application executor
                 -> managed device endpoint
```

- Browser只持有会话标识、脱敏数据和一次上传/下载令牌；不得持有设备密码/私钥和可复用服务凭据。
- 入口代理只接受已登记域名、TLS配置和请求大小；内部管理/健康端点不得直接暴露公网。
- 后端是业务授权和状态机边界；数据库、Redis和文件存储不直接接受终端用户连接。
- 外部ACL只连接`12-integration-design.md`登记的目标；用户输入的URL、回调地址和设备端点不能直接成为服务端任意出向目标。
- DAC秘密经受控同步链路进入本次任务执行进程内存，任务结束、失败、超时、撤销或会话关闭后清除引用与缓冲。

【方向已确认：P3-E01】按ADR-0004复用企业现有网关/LB、证书和网络区。依据ADR-0018，实际平台、TLS终止、域名、应用/数据节点、管理通道拓扑及运维Owner在部署阶段指定；不阻断本逻辑设计基线，但未登记前18分册不能给出目标环境生产放行结论。

## 4. 身份、会话与服务认证

### 4.1 用户认证

- LDAP/AD断言必须校验issuer、audience、签名、时效、nonce/重放和目录账号唯一映射；认证成功只建立平台身份。
- 平台角色、项目角色、组织范围、设备/文件/凭证专用权限在每次请求由服务端加载，不把目录组直接等同于业务角色。
- 本地应急账号只在既定安全策略启用，单人单号、强制审计、不可共享；不得因LDAP/AD不可用自动开放公共管理员账号。
- 会话Cookie必须`Secure`、`HttpOnly`、`SameSite`；认证Token不写入`localStorage/sessionStorage`。会话有效期、空闲超时和并发会话策略【待安全Owner在P3-E01环境配置登记】，普通租户不可降低。
- 登录、会话刷新、登出、失败、锁定和应急账号使用均进入安全审计；错误响应不区分“账号存在但无权”等可枚举细节。

### 4.2 服务与后台任务

- 每个外部ACL、回调Consumer、迁移、调度和DAC执行服务使用独立服务身份；禁止共享管理员用户Token。
- 服务身份只拥有接口代码、方向和业务对象范围内最小权限；密钥从环境密钥源注入，不进入代码、镜像、Git或业务配置表。
- 回调、内部管理API和取密API必须同时校验服务身份与任务/对象绑定；只认证服务而不校验业务对象不够。

## 5. 授权与数据隔离

授权顺序固定为：认证主体→tenant→功能权限→组织/项目/合同/设备数据范围→对象专用权限→状态/版本→业务门禁。任何失败不产生业务写入或成功幂等记录。

| 场景 | 服务端证据 | 拒绝要求 |
|---|---|---|
| 项目/任务树 | ProjectTreeScope、treeVersion、主体项目角色 | 平级默认不可见；父级只查看明确授权后代；错误不泄露敏感子节点 |
| ProjectTask业务工作台 | TaskWorkBinding版本、ProjectTreeScope、绑定类型、适用的目标对象权限与业务状态 | TASK_NATIVE按任务范围返回通用详情操作；其他类型的VIEW/EDIT/APPROVE/CREATE由服务端合并授权，目标对象无权时拒绝，不回退为通用任务编辑权限 |
| 设备/实施/割接/巡检 | DeviceCurrentAssignment、祖先投影水位、业务对象范围 | 越级设备不可查、不可操作；投影延迟时写操作回源真值 |
| 合同订单 | ERP来源映射、ContractProjectScope、DeliveryScope | 不得因项目权限自动获取全部合同金额/订单范围 |
| 文件 | FileReference业务对象、文件版本、操作类型 | 下载/预览/替换/归档分别校验；签名URL短期且绑定主体/操作 |
| 设备凭证 | 用户、凭证、设备、协议、命令模板、有效期五元组及任务 | 创建人默认可用；扩大范围显式授权；管理员身份不隐式取密 |

权限收缩、凭证撤销、文件失效和成员移除先更新真值并推进权限版本；敏感读/写必须回源，不能继续信任旧缓存。

## 6. Device Access & Collection秘密安全

### 6.1 存储和密钥

- DeviceCredential保存密文、算法、密钥版本、账号掩码和元数据；不存在业务查询可获得的明文列。
- 数据加密密钥与主密钥/密钥加密密钥分离；业务数据库只保存密文和密钥版本，不保存可解密主密钥。
- 【方向已确认：P3-E04】按ADR-0004使用企业KMS/Secrets Manager；依据ADR-0018，安全/运维在部署阶段登记具体设施、访问策略、轮换、备份、吊销、应急Owner和审计接口。不阻断本逻辑设计基线，但未登记前设备凭证能力和NFR-02生产发布不可放行。
- 密钥轮换生成新凭证版本；新任务使用新版本，已开始任务按冻结授权快照完成或被撤销，历史审计不改写。

### 6.2 取密和临时输入

- 已保存凭证只允许受信任秘密代理在有效任务授权下取用一次；返回值绑定任务、设备、协议、命令模板和失效时间，不可复用。
- 临时模式保存登录用户名和认证方式，临时密码必须不落库；页面禁止自动填充、草稿恢复和浏览器存储；刷新/重试/再次执行必须重新输入。
- `saveAsCredential=true`时凭证、创建人默认授权和任务原子创建；本次任务切换到新凭证及授权快照，失败不降级为临时任务。
- 请求正文日志、APM正文捕获、异常详情、消息、回调和结果文件均对秘密字段使用结构化禁止策略；不能依赖事后正则脱敏作为唯一控制。

### 6.3 撤销与泄露处置

- 连接前撤销立即拒绝；连接中撤销停止后续命令并关闭会话，无法安全中断的当前命令只等待返回/超时，记录实际停止点。
- 发现唯一标记测试秘密或真实秘密进入禁止面时，立即停止相关通道、撤销任务授权、轮换受影响凭证/密钥、限制原证据访问并启动安全事件；不得删除原失败证据后重跑掩盖。

## 7. API、输入、输出与浏览器安全

- 所有请求使用声明式Schema校验类型、长度、枚举、精度、时间区和集合上限；业务唯一/状态/授权仍由服务层校验。
- SQL使用参数化Mapper/查询构造器；禁止把筛选、排序列、表达式或模型输出直接拼接SQL。
- Vue模板使用框架转义；富文本仅允许经批准的白名单净化器，禁止把用户、外部接口、iframe或模型返回文本当代码或使用不受控`innerHTML`。唯一例外是F-PLT-002明确修订中由高信任模板发布者配置的FormCreate事件、函数和`parseFunc`，仅由既有运行时在当前登录用户浏览器执行；它不是外部文本执行许可。
- 状态命令必须使用明确action API和`If-Match`/幂等键；通用PATCH不得修改status、tenant、Owner来源字段或授权范围。
- CORS只允许已登记来源并与凭据策略一致；不使用`*`+credentials。生产响应启用HSTS、CSP、X-Content-Type-Options、frame-ancestors/X-Frame-Options、Referrer-Policy等安全头，具体域名和CSP源【待P3-E01登记】。
- 错误响应只返回稳定错误码、requestId、可公开消息、currentVersion/status等必要字段；不返回堆栈、SQL、内部URL、存储键、认证头、对象是否存在的越权细节。
- 认证、取密、文件上传、批量导出和外部回调按主体/接口/租户应用受控限流；数值基于19压测与环境容量登记，不能用限流掩盖50并发门禁。

## 8. 文件、导出和数据安全

1. 单文件最大50MB；超过限制在传输前或受控接收阶段拒绝，不创建业务可见FileArtifact版本。
2. 上传会话校验声明大小、实际大小、SHA-256、MIME、扩展名和必要魔数；对象存储键由服务端生成，文件名只作为展示元数据。
3. 文件病毒扫描默认关闭；关闭时不调用Provider并记录`SKIPPED`，不得解释为扫描通过或安全。部署启用扫描后，未通过的文件保持隔离且不可预览、下载、引用或归档，扫描服务不可用时失败关闭且不得降级为`SKIPPED`。
4. 下载、预览和归档实时校验FileBusinessScope；访问令牌短期、操作绑定、不可越租户复用。
5. CSV/Excel导出防公式注入；PDF/DOC/XML预览与解析在受限进程执行，不执行宏、脚本或外部实体。
6. Word正文不做内容级审计，但文件身份、版本、哈希、替换、下载、归档和业务审批动作留痕。

## 9. 外部集成与出向访问

- 每个接口使用12分册注册的系统Owner、方向、目标、认证、字段映射和来源/幂等键；无注册目标禁止出向。
- 用户可影响的设备端点仅允许业务授权设备，并校验协议、端口及解析地址；平台通用服务不得成为任意URL/端口代理。
- 外部URL仅允许HTTPS/批准协议、登记主机和网络区；解析结果命中loopback、link-local、私网或保留地址时按接口注册网络策略拒绝，禁止跟随到未登记目标的重定向。设备管理网络的私网目标必须通过独立DAC网络区和设备授权表达，不能放宽通用HTTP ACL。
- F-PLT-002首版完整保留FormCreate浏览器侧API选择器和iframe配置，不建立URL/域名白名单；该选择由需求方接受为获权模板发布者的高信任配置。它不经过服务端出向ACL或代理，仍受浏览器CORS、CSP、frame策略及目标API自身认证、租户和数据范围约束；失败如实展示，不产生表单保存或其他Context业务成功事实。后续收紧只能经前向规格和新模板修订实施，不改写既有发布修订。
- 回调验证服务身份、签名、时间/nonce、callbackId、任务和序号；验签失败隔离，重复幂等，乱序不得回退终态。
- 请求/响应日志只保存脱敏摘要、状态码、版本、耗时和证据引用；认证材料、秘密和完整敏感正文不落业务日志。

## 10. 数据库、缓存与供应链

- MySQL账号按应用、迁移、只读运维分离；应用账号无DDL权限，Flyway账号只在迁移窗口使用。生产账号和权限【待P3-E01/E02登记】。
- Redis不保存临时密码或凭证明文；缓存key含tenant/scope/version，不使用用户可控原文；敏感写和权限判定回源真值。
- 备份内容与生产数据同等级加密、授权和审计；RPO/RTO、介质和恢复演练由P3-E03确认。
- 后端使用Maven锁定依赖树/制品校验，前端在实际安装根目录使用`corepack pnpm@9.15.5`与`--frozen-lockfile`；当前默认PATH的Java21和根目录pnpm11不得作为构建证据。
- 发布前执行后端/前端原生依赖审计和可达性分级；不得自动使用强制升级跨越依赖范围。高危/严重且生产可达问题必须修复或形成有Owner、到期日和补偿控制的批准例外。

## 11. 审计不可用与安全事件

| 情况 | 行为 |
|---|---|
| 高风险管理操作无法写不可变审计 | fail closed：拒绝凭证授权/取用、权限/角色、项目层级、审批例外、文件归档、集成人工补偿和关键状态命令 |
| 普通只读运行日志后端不可用 | 业务可按17分册受控降级，但本地结构化日志不得包含秘密；恢复后核对缺口 |
| 检测到秘密泄露 | 停止通道、撤销授权、轮换、限制证据、告警和复验 |
| 认证/回调重放攻击 | 拒绝、记录来源/摘要和安全事件；不推进状态 |
| 依赖或制品校验不一致 | 阻止发布；保留构建环境、锁文件和差异证据 |
