# SDS Phase 1：数据 Owner 矩阵

| 数据事实 | Owner | 其他领域使用方式 |
|---|---|---|
| 到货、安装、实施结果解释、实施风险、质量/安全检查、实施证据语义 | Implementation Execution | 通过查询、快照或事件引用 |
| 设备身份、档案、服务状态、RMA/维保基本信息 | AST | 实施和服务只引用，不直接修改主档 |
| 凭证、授权、采集任务、外部执行状态、原始结果引用、回调证据 | PLT/采集能力 | 实施、割接、巡检通过任务契约使用 |
| 割接任务、评估、方案、审批、执行 | CUT | 实施只提供上线门禁快照 |
| 巡检任务、规则、报告、问题和服务状态 | SRV | 通过设备和采集任务引用 |
| 交付件齐套、验收、归档、闭环和交维 | ACC | 读取实施证据，不覆盖原始事实 |
| 合同、订单行、交付范围和履约对账 | COM/外部CRM | 项目按范围引用，不能超分配 |

`CollectionTask` 不属于 Implementation Execution；实施执行域只拥有业务结果解释和证据关联。
