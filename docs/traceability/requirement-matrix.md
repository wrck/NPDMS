## 字段状态约定

| 状态 | 含义 |
|---|---|
| `BASELINE` | 已纳入PRD V1.7正式基线 |
| `NOT_STARTED` | 下游工程资产尚未生成，不代表需求缺失 |
| `BLOCKED_BY_SPEC` | 存在业务语义冲突，必须回到CHG-01或决策记录 |
| `BLOCKED_BY_EVIDENCE` | 缺少数据、接口、迁移或测试证据 |
