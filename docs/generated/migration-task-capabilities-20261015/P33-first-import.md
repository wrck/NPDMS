## 规则复用与跨批次处理

`DppmsInstallationRecordMigrationService` 的原字段检查、历史区间、状态和审计转换、地址快照、正式基线比较及当前位置填空调用，提取到 `InstallationHistoricalCarryRules`。旧记录纠正与首次插入共用这些规则；旧路径的完整基线、版本、状态保护继续保留。

首次入口仅增加正式安装编号、记录 ID、地址/快照创建及 INSERT。原 ID 仍是来源身份，不作为正式安装 ID。已绑定记录只回读校验，不再次插入或覆盖。

来源读取仍按原自增 ID；INT 将当前只读快照的范围内原行写入本地临时分区文件，完整读取后按设备归集。同一设备的全部历史在同一业务事务交给 IMP，来源分块不会把它拆开。IMP 线性选出该设备最新来源行后，复用原有规则处理其余记录；已有更晚的正式安装及当前位置不覆盖。不同项目的同一 SN、相同最新时间、未经裁决的转移字段、历史基线变化继续阻断。

本地暂存显式保留 NULL 和历史时间精度，不写来源数据库或业务暂存表。每个分区受既有 `maxBytes` 预算约束，超限报错，不截断设备历史；正常结束或异常退出执行文件清理。进程被强制终止时的临时文件不属于可恢复检查点。失败重跑从来源起点重新读取，已提交设备通过原绑定和正式基线校验。
