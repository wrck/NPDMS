# 施工计划提交审批调整理由验收

按用户要求，首次施工计划提交审批无需调整理由；项目已有生效计划时，调整理由移至提交审批弹窗填写并必填。阶段和任务日期的编辑、保存不再要求填写理由。项目详情与独立阶段施工计划入口同步调整。

后端详情提供 adjustmentReasonRequired，由当前项目是否存在生效批次决定；提交命令独立接收 adjustmentReason，已有生效计划时拒绝空值，不以草稿旧备注替代本次提交理由。理由随本次审批提交保存，原授权、版本冲突、输入快照、日期校验和审批状态机保持。
