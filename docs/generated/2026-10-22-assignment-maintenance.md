# 人员指派完成后维护修正

来源：本次用户要求人员指派与用户信息录入操作界面一致，完成后仍可继续维护。

根因：ProjectFlowPanel 对 DONE 任务统一传入 readonly；人员指派又经过任务执行宿主，而用户信息录入使用项目业务维护入口。

实现：仅对服务端业务上下文明确为 PROJ / PROJECT_ASSIGNMENT / PROJ_PROJECT_ASSIGNMENT 的已完成任务，展示已有项目成员维护面板。任务仍为完成，不恢复执行上下文，不调用已完成任务的结果刷新命令。保留阶段未进入、关闭/取消、上下文错误和原项目成员权限、项目状态、版本及历史规则。新增成员接入统一工作区操作栏，独立页面保留原入口。

验证：TaskBusinessPanel.runtime.spec.ts、TaskBusinessPanel.recovery.runtime.spec.ts、ProjectMembersPanel.runtime.spec.ts 共 36 项通过，覆盖完成后维护、只读及上下文错误、其他已完成任务只读、离开守卫和禁止重跑已完成任务命令。

真实浏览器：10.210.0.11:19191，吉林省纪检监察外网省级平台建设，人员指派显示完成 100%；统一操作栏包含刷新、新增成员；新增项目成员及编辑项目成员表单均可打开。均取消，未保存或移出成员；未验证实际写入。未重启后端，未提交或推送。
