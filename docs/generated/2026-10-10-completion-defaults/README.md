# 完工证明新建默认值修复证据

需求方最终明确：设备清单按订单行汇总；序列号页面保留完整SN记录。完工证明的新建设备类型、型号及数量应与设备清单一致，迪普工程师及联系方式应默认带入当前用户资料。

## 实现边界

- 仅修改当前前端消费者，复用项目范围、订单行、产品资料及本人资料的原生接口，未调整服务端授权、生命周期或数据库。
- 项目数量取当前项目订单行交付范围的 `allocatedQuantity`，按产品编码汇总，不数SN或范围拆分明细。型号使用精确产品编码匹配的产品资料，名称保留订单描述；可手动调整。
- 编辑已有草稿保持已保存设备和联系方式，包括手动清空的设备行。来源后续页失败不会保存部分数量，关闭后的迟到结果丢弃。
- 设备清单的发货数量来自所引用ERP订单行，不把SN统计或未知值当成发货事实。
