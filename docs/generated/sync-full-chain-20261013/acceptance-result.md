- 原有 15 张源表的计数和校验和、19 个原对象定义保持一致，只增加授权的四个本轮复用辅助对象。
- 候选工作树 12,851 个文件及 Git 状态保持一致。
- 运行过程中多次连接中断通知均有原进程 PID/start ticks、MySQL/Redis epoch 连续性核验记录；未因此重启容器或重新启动基准。
- 观察器 `COMPLETE_WITH_ERRORS`：76 次 TimeoutExpired，其中 70 次 heap-sample、6 次 resource-sample。采样峰值存在缺口，不应描述为连续无损监控。

- 目标库分配空间：14393905152 字节。
- 最低可用磁盘：2775142400 字节。获准的 2 GiB 守卫未触发；binlog 保持开启。

- V7/V15 GC 事件数为 1067/471，视图最大暂停为 23.6/468 ms；不能只用次数或最大值推导总 GC 停顿占比。

- 当前结果同时存在数据库批处理普遍变慢及 JVM 调度/暂停异常的迹象，尚缺可比窗口的资源证据，不能归责单一代码改动或直接免责为云环境问题。
