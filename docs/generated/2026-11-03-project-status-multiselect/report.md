# 项目列表状态多选

2026-11-03。用户将新增S0～S6合计卡片的需求调整为状态多选，并要求默认选中S0～S6。本次实现该替代方案。

## 行为与边界

- 初次进入项目列表及点击重置时，默认选择S0～S6；状态控件支持多选及选中项折叠提示。每次变更从第一页查询，保留其他筛选条件。
- 可组合选择阶段和三种闭环状态，按并集查询。S0～S6仍仅包含ACTIVE项目，保留阶段值的闭环项目不混入阶段结果。
- 清空选择或点击“项目总数”查看全部可见项目；单状态卡点击筛选、再次点击取消。统计卡独立于列表条件的既有口径保持不变，列表总数显示本次筛选结果。
- 分页新增可选statuses参数，保留原status；两者同时传入取交集。显式空集合返回空结果，UI清空选择时省略该参数。租户、删除标记、PROJECT_VIEW范围、其他筛选与分页不变。
- 直接复用当前复数路由项目主档分页、统计和组件；未改历史单数项目入口、状态机、数据或种子，无数据库迁移。
