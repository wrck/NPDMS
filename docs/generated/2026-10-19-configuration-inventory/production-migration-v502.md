## 失败路径

在本次专用库中验证：

- 预留 ID 已被其他配置占用时，迁移拒绝覆盖，之前插入的规则一并回滚。
- 已有不同内容的表单草稿时，迁移拒绝替换，之前插入的数据一并回滚，草稿内容保留。
- 修改旧已发布割接维度仍被原 `CUT_PARENT_FROZEN` 触发器拒绝，证明迁移没有关闭历史保护。

新迁移显式处理文本排序规则差异，并保持所有触发器生效。失败仅发生于本次隔离演练；没有对现有数据库执行 repair、删除历史或重放旧迁移。
