# 割接客户等级手选恢复与隔离浏览器验收

日期：2026-10-25。修复范围仅为割接新建／等级确认页选择项目后的客户等级读取，不改其他页面布局、不回写客户等级、不修改已有评估、审批或结项记录。

## 原因与修复

旧新建页选择项目后只读取共享项目摘要，问卷的完整等级事实直到选择设备才加载。因此当前客户没有维护等级时，页面也先显示“未获取”，没有手选入口。CUT项目选择查询还直接使用PROJ中的customerId，没有复用已有的同租户客户编码解析，部分只有客户编码的项目因此丢失等级来源。

修复复用CUT项目上下文端口及CUS当前等级查询。在既有CUT项目选择响应保留原字段，新增customerServiceLevelContext；页面选项目后立即读取，不再依赖设备选择。NOT_CONFIGURED显示原字典手选，AVAILABLE沿用原只读逻辑，UNAVAILABLE或资料损坏不当成未维护。切换项目清空原手选值，迟到响应不能覆盖新项目。设备和保存／提交的原来源、权限、版本与幂等校验保持。
