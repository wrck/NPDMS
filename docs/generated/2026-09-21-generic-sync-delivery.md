# 通用同步引擎与四项配置模板交付记录

本次依据用户专项授权实施，不走工程实施链。交付范围是新增模块能力，未执行真实数据同步，未回写 Feature、PRD 或发布状态。

## 已实现

在既有数据迁移与同步模块内增加 `TABLE_MAPPING` 通用方式。现有业务适配器继续保留。普通表同步通过配置目标表、业务唯一键和字段映射完成，不需要编写实体专用适配器。

- 来源支持既有表读取、只读 SQL、整批、游标分页和流式分块；任务使用独立 `taskKey`，同一来源系统可以配置多个通用任务。
- 一个来源行可以执行多个有序目标步骤，支持前序目标 ID 引用、可选步骤、关联查找与显式主目标。
- 写入支持新增并更新、仅新增、跳过已有、仅更新；更新字段及空值覆盖方式可以配置。
- 字段映射复用原编辑器，支持直接值、常量、默认值、类型转换、枚举映射、日期和 JSON。
- 最新值可以按时间及同时间数值列比较；条码模板使用发货时间及发货事件 ID，保持与现有最新发货查询相同的排序维度。
- 预览检查目标字段、非空/长度约束、唯一键、关联结果及受保护字段，提供目标前后值。预览中的新 ID 为内部负数占位，不作为实际目标 ID 返回。
- 来源记录、运行、断点、来源映射及问题处理复用现有模块；多目标血缘记录各个实际目标。可选关联未命中或歧义保存在结果及映射的 `_warnings` 中；不能完成的行进入既有问题记录。
- 已删除记录不能由同步恢复；不可变发货事件的事实字段出现差异时报冲突；目录明确排除来源同步时间等技术字段，原历史载荷仍不覆盖，新读取的载荷保留在本次来源证据中。主目标被跳过时整行不写，数据库异常回滚当前分块，避免部分目标残留。

## 四个模板

| 任务标识 | 来源与目标 | 默认行为 |
| --- | --- | --- |
| `shipment-contract` | `fb_contract` → `com_shipment_contract_reference`，补充已有合同属性 | 按来源键保留发货归属事实；公司只从 ERP 订单唯一解析，关联缺失保留来源并提示；不以发货记录创建合同主档 |
| `shipment-package` | `fb_shipment` → `com_shipment_package` | 字段映射，按 `con_id` 查找发货合同归属，来源键幂等 |
| `shipment-barcode` | `fb_shipment_barcode` → `ast_device`、`ast_device_shipment` | 主/附加 SN 主档按 SN 去重；每条来源行保留发货事件；更新最新发货缓存，旧事件不覆盖新缓存；RMA 原值保留，未确认动作使用 `UNCLASSIFIED` |
| `contract-master` | ERP 订单按公司编码＋合同号分组 → `com_contract` | ERP 形成唯一主档；回款、发货补充非空属性；客户冲突记录问题；同号跨公司不猜测来源属性归属 |

合同生成遵循本次确认：金额、币种编码、有效期、来源状态等缺失权威字段保持待补齐。默认主档 `authority_status=PENDING_AUTHORITY`，未知状态为 NULL。来源补充不覆盖客户、合同类型、合同金额、币种编码及生命周期等 ERP 权威字段。

合同生成模板按来源中可用的更新时间/来源 ID 选择非空属性，发货属性在回款属性之后补充；发货合同模板按 `contract_id` 顺序读取。该顺序是明确的模板配置，不是引擎隐藏的实体规则。合同来源中不存在的系统/拓展编码不会自行生成。

建议首次执行顺序：合同主档生成 → 发货合同同步 → 合同装箱单同步 → 发货条码同步。四项为独立暂停任务模板，不会自动串行启动其他任务。

## 扩展方式与写入边界

- `pms-module-integration/src/main/resources/sync/generic-targets.json` 是服务端目标能力目录：允许写入的表、字段、业务键、可更新字段、只读关联表及系统初始化值。
- `pms-module-integration/src/main/resources/sync/generic-templates.json` 是四项模板。已有目录内的新任务只需在页面配置；增加目标表只需审定目录声明，不需要新增 Java 实体适配器。
- 配置接口仍使用 `pms:integration:configure` 权限，执行仍走现有运行权限与事务。租户取自服务端上下文，审计字段及受保护初始化值不能由映射覆盖。
- 本次专项的动态 SQL 仅位于 `GenericSyncJdbcStore`：标识符来自服务端能力目录，值使用 JDBC 参数绑定，不提供任意目标 SQL、删表、清空或关闭约束能力。这是已授权通用迁移能力的专用基础设施，不改变普通业务 Mapper 和跨模块业务接口规则。
