## 5. 初次配置时的接入缺口

以下五个任务在四类常规模板中明确保留空完成规则。Compiler各返回5项`REQUIRED`，因此不能发布；没有用恒真、手动完成或任意附件满足这些业务条件。

| 任务 | 清单要求 | 已核实的接入缺口 |
|---|---|---|
| 到货签收 | ArrivalAcceptance实体创建并确认 | 源配置是旧到货页面加签收附件；当前模板完成事实目录无对应确认事实。旧`arrival`证据提供方不能等同新的到货验收实体 |
| 硬件实施 | 当前实施范围内全部设备安装完成 | 有全设备安装结果提供方，但运行目录`IMP/INSTALLATION/INSTALLATION_COMPLETED`的`commitBarrier=false`，不满足模板结果订阅契约；源文件完成规则也不等同设备全量完成 |
| 割接上线 | CUT割接任务实体审批通过 | 源`APPROVAL`绑定启动的是PROJ模板任务审批，没有CUT实体身份；审批通过不能伪造CUT实体审批或实际割接成功 |
| 现场培训 | 培训实体客户确认 | `TrainingDeliveryEvidenceProvider`能验证客户确认，但当前模板完成事实目录及相应可直接复用的实体限定任务接入未就绪；源配置仍为手动任务加文件 |
| 项目闭环 | 正常闭环审批通过后完成S6任务 | 当前正常闭环申请前检查末阶段完成和全部任务DONE，与等待审批的S6任务形成循环，需要正式闭环接入 |
