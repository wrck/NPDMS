# 到货签收上传与项目交付件关联验收

## 问题与修改

项目详情“到货验收与签收”由 ProjectArrivalReceiptPanel 承接，原上传入口仅保存 infra 文件 URL。真实项目 992203060198 的签收记录 30022、30023 已签收，但 D_ARRIVAL 为 PENDING 且没有提交历史。当前冻结计划已明确配置 IMP.ARRIVAL_SIGN_DOCUMENT 自动归集，规则无缺失。

项目入口改为选择签收单、保存时建立真实待签收记录并按 IMP/ARRIVAL/{id}/ARRIVAL_SIGN_DOCUMENT 的固定 arrival-sign-document 引用键完成统一文件上传，然后复用原更新、签收命令。完成时间取上传成功时刻；原到货时间必填校验保留，上传前待签收记录使用登记时间。失败保留记录与上传会话，重试不重复新建，丢失签收响应时回读实际状态。已签收与只读工作区不可编辑，详情加载失败禁止保存。

现有详情接口增补当前签收单文件编号、版本、引用版本，复用 FileArtifactApi 的租户、项目范围和文件权限。文件回显使用共享引用组件；旧附件 URL 和签收历史保留。没有更改冻结计划、状态机、Mapper 查询或引入数据库迁移。
