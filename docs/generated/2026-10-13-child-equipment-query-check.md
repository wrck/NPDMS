## 修复结果

`MaterialDevicePicker.vue` 原来用 `Number.isSafeInteger(projectId)` 判断项目有效性。当前 Long ID 在前端以十进制字符串传输，该判断会拒绝合法子项目。现复用既有 `isBusinessViewId/legacyOwnerId`，保留原始 ID；已经丢失精度的数字、非法字符串及超出 Java Long 范围的 ID 仍拒绝，不转成空条件查询。

物料候选原来只读取交付范围第一页 200 条，再在前端分页。现先读取全部范围页，再按既有合同、产品规则分组。后续页失败或未读完总数即出现空页时，不展示部分候选；已有草稿选择保留。范围引用、数量校验、目标换货产品、服务端授权和保存校验未修改。
