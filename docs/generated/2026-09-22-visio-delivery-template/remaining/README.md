## 已落实的用户决定

施工计划与实施方案从工前准备完成后并行，二者完成后才进入实施部署；施工计划页审批文案按“审核施工计划”。本模板非直签跳过初验和终验，进入现场培训；CRM 改单、物料申领、外采事前申请为独立支线，不设统一回流或等待支线审批全部结束的汇合条件。配置工具自动检查按确认忽略。

工前确认表由项目有效项目经理填写，三个物料判断由已发布动态表单定义，提交记录包含填写人、时间、表单修订和完整值快照。服务器校验必填、当前项目经理、项目状态、表单版本和前一确认身份；修改产生新记录，历史只读。原厂不提供辅料时不触发物料申领/外采分支；原厂提供辅料后按 BOM 判断进入相应支线。

重大项目按 CRM 属性判定：`办事处级重大项目`、`市场部级重大项目`、`公司级重大项目`三值命中时，服务经理审核后由工程管理部复审。两个版本内规则分别限定重大复审和普通审核，级别缺失继续按 SCH-05 阻止提交。服务器决定审核级别，人工选择普通及旧普通审批接口不能绕过规则；提交时留存规则、源属性、项目版本及模板修订，在审实例不随来源或规则变化重新选路。配置值仅位于模板规则，不写死字段名称或 CRM 值在 Java/前端条件表中。
