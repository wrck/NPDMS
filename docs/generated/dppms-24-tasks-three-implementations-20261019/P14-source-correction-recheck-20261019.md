正式表的同租户父头外键只约束真实order_id存在，**没有数据库CHECK强制头行类型相同**；当前类型匹配阻断来自迁入身份映射/关联逻辑，不能误称为数据库限制。正式order_no、order_id必填及(tenant_id,order_id,line_no)唯一键保持。删除类型条件是否会错误归父或造成同行号冲突，必须先有明确的关联规则；不自动修改lineType、头orderType、数量或状态。
