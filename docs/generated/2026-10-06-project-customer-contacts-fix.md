# 项目客户联系人操作修复

## 问题与范围

用户反馈客户信息页和任务办理区均无法维护项目联系人。2026-10-06 在 `PJT2026000035 / 用服test / 992203060176` 的真实页面复现：客户编码 `162021000700` 能正常展示客户详情，但项目存储的客户内部 ID 为空，联系人上下文因此被判定为未关联客户，新增及载入按钮被禁用；客户概览还隐藏了客户选择框，形成无可用关联入口。

## 修复

- PROJ 联系人上下文在项目内部客户 ID 为空、现有客户编码非空时，通过 CUS 既有 `getCustomerByCode` API 精确回源；保留客户查询权限、数据范围和租户检查。读取和锁定写入路径共用该上下文，不修改项目客户字段、客户主档、历史或生命周期状态。已有内部 ID 保持优先，编码不可解析时拒绝，不按名称匹配。
- 联系人组件对真正未关联客户的项目显示客户选择框，即使概览关闭客户筛选展示；继续使用已有显式关联接口，不新增业务流程。
- 客户信息和任务办理区均复用同一组件/API；阶段未准入的只读保护未改动。
