# ADR-0011：生产Trace采样策略

## 状态

Accepted（采样比例已批准，生产配置与实测证据待提交）

## 日期

2026-08-13

## 适用范围

生产环境中平台、基础设施和外部集成链路产生的分布式Trace及Span。

## 决策

- 普通成功请求按10%保留，策略代码`TRACE_STANDARD_SAMPLE_10_PERCENT`。
- 错误链路、高风险安全操作、审计写入失败及发布/迁移链路按100%保留，策略代码`TRACE_CRITICAL_SAMPLE_100_PERCENT`。
- 优先采用能够识别最终结果的尾部采样或等价机制；若组件只能头部采样，必须通过强制采样标记、错误补充事件或等价手段保证强制类别100%保留。
- 未被Trace采样的请求仍必须产生规定的指标；业务事实、审批历史及明确留痕操作仍按ADR-0006永久记录。

## 强制100%类别

- 服务端错误、未处理异常、超时及外部调用最终失败；
- 凭证取用/拒绝/撤销、跨租户或高风险权限拒绝、安全事件；
- 不可变审计写入失败或高风险动作因审计不可用而fail closed；
- 发布、数据库迁移、数据迁移、切换、回退/前滚和恢复演练。

## 边界

- 10%是普通成功请求的生产基线，不适用于性能压测的采样配置；压测配置须随性能证据单独登记。
- 采样不得降低脱敏、秘密扫描、租户隔离或Trace访问控制。
- P3-E05继续保持`OPEN`，直至生产采样配置、强制类别命中率、链路完整性和开销证据通过复核。

## 验收要求

- 大样本普通成功请求的实际保留率与10%配置一致且无业务维度歧视；
- 注入错误、高风险操作、审计失败及发布迁移事件，Trace保留率均为100%；
- 未采样请求的指标连续，永久业务事实和审计完整；
- 采样后的Trace仍满足ADR-0008的分层留存及秘密零命中要求。

## 重新决策触发条件

- 生产容量、成本或性能证明10%不可持续；
- 故障定位或安全响应证明普通请求采样不足；
- Trace采集架构或强制采样能力发生实质变化。
