# ADR-0025：V1.7 P3-E09 物理模型差量

## 状态

`PROPOSED_FOR_REVIEW`

P3-E09 继续保持 `BLOCKED_BY_REVIEW`。本 ADR 固化可复核的 63 表候选 DDL，不以 DDL 可执行替代独立审核或批准。

## 日期

2026-08-13

## 需求依据

PRD V1.7：`ACC-02`、`CLO-01`、`CLO-02`、`SUB-03`、`SUB-04`、`CUT-11`、`SRV-01`、`EQP-01`、`EQP-02`、`EQP-03`、`EQP-05`、`EQP-07`、`EXE-03`、`INT-05`。

本 ADR 只把已确认对象落为物理表、业务键与历史约束；字段是实现这些既有语义的设计，不构成新的 PRD 角色、状态、流程节点、门槛或数据权属。

## 决策

核心迁移 DDL 从 50 表扩展为 63 表，并按对象登记精确差量：

| 对象 | 新增目标表 |
|---|---|
| ConfigurationCollectionResult | `imp_configuration_collection_parse_attempt`、`imp_configuration_component_candidate` |
| SatisfactionCollection | `acc_satisfaction_collection_task`、`acc_satisfaction_questionnaire`、`acc_satisfaction_response`、`acc_satisfaction_result` |
| CutoverSupportTask | `cut_cutover_support_task`、`cut_cutover_support_history` |
| ResponsibilityInterval | `cut_cutover_support_responsibility_interval` |
| HistoricalWorkOrderRecord | `srv_historical_work_order` |
| HistoricalTimeRecord | `srv_historical_time_record` |
| DeviceComponentRelation | `ast_device_component_relation` |
| DirectorySyncSnapshot | `plt_directory_sync_snapshot` |

### 业务键与版本/时态

- 配置解析尝试按租户、采集结果和尝试序号唯一；板卡候选按租户、解析尝试和候选序号唯一。原始配置 Log 由证据引用保留，解析候选不得直接改写已生效设备关系。
- 满意度任务按来源对象和整改重收序号唯一，并冻结模板版本、阈值和状态机版本。问卷实例、答卷、签字与评分结果追加保存；整改重收创建新任务/版本，不覆盖旧答案或旧判定。
- 割接保障任务按任务编号永久唯一，同一割接逻辑引用、冻结范围和时间窗不重复。状态/动作历史和责任区间按序号追加；接管或转交结束旧责任区间并新增，挂起不结束责任区间。
- 历史工单与工时按租户、来源系统和来源业务键永久唯一，只暴露 `source_*` 原始分类、状态和责任人，不提供可继续流转的当前业务状态，也不使用软删除清除历史。
- 设备组件关系保存机框、槽位、板卡、关系来源、证据和生效区间。`effective_to IS NULL` 生成当前槽位标记，同一租户、机框和槽位最多一条当前关系；换板结束旧关系并新增。
- HR 通讯录快照按租户、来源系统和来源键唯一，保存来源版本、人员、组织、岗位、任职状态、同步批次和水位；来源停用不删除已经固化的历史责任引用。

### 不可变历史与来源证据

问卷、答卷、评分结果、割接动作历史和责任区间采用追加模型。历史工单/工时保留不可变来源载荷及 SHA-256，配置解析和组件关系保留原始证据引用。任何历史异常进入迁移问题与来源证据链，不通过覆盖、软删除或伪造当前状态修正。

### 边界

- 跨 Context 只保存逻辑引用，不新增跨 Context 外键，也不允许外域模块直接写本域表。
- 当前状态字段只属于满意度收集任务和割接保障任务聚合；所有状态迁移仍必须经过相应状态机/应用服务。历史只读记录不是新的 WorkOrder 聚合，不能恢复通用工单流转。
- V3/OUT_OF_SCOPE 表不进入本次 DDL。旧 `dppms` 只读；迁移按来源对象逐项提取、转换、装载、核对，不执行旧库 DDL/DML，不使用跨数据库 SQL。

## 验证与批准条件

机器契约和验证器必须拒绝任一目标表缺失、对象映射偷换、V3/OUT_OF_SCOPE 混入、跨 Context 外键、历史表可变状态/软删除字段以及关键追加/时态唯一约束缺失。全部派生迁移证据必须与同一份 DDL SHA-256 一致，并在隔离 MySQL 8.4 执行成功。

上述结果只形成 P3-E09 候选证据包；独立审核与批准仍是解除 `BLOCKED_BY_REVIEW` 的必要条件。
