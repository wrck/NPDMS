# ADR-0016：导出文件24小时有效期

## 状态

Accepted

## 日期

2026-08-13

## 决策

- 业务导出文件自生成成功起保存24小时，策略代码`EXPORT_FILE_TTL_PT24H`。
- 到期自动删除文件内容；如仍需使用，用户必须基于当时实时权限重新导出。
- 文件到期不删除导出记录。Q7不创建独立审计对象，而是在ADR-0014定义的同一`ExportTask/ExportAudit`中追加文件过期与清理结果；申请、范围快照、条件、字段、结果数量、文件引用、生成/失败/拒绝结果、操作者和下载记录均永久保留。
- 下载时重新校验原主体的导出功能权限、数据范围和字段权限；权限撤销后即使文件未到期也拒绝下载。

## 验收要求

- 文件在24小时内可由仍具权限的原主体下载；到期后内容不可获取；
- 到期清理有结果记录，导出与下载审计仍可完整查询；
- 重新导出形成新的文件和新的永久留痕，不复活旧文件。
