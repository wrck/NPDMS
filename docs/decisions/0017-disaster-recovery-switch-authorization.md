# ADR-0017：灾备切换授权

## 状态

Accepted

## 日期

2026-08-13

## 决策

- 灾备切换由运维负责人发起，业务负责人确认后执行，策略代码`OPS_INITIATE_BUSINESS_CONFIRM`。
- 涉及安全事件时，必须增加安全负责人确认，策略代码`SECURITY_CONFIRM_WHEN_INCIDENT`。
- 发起、确认、拒绝、执行、失败、回切及最终业务验证全过程永久留痕。
- 不设绕过确认的普通管理员路径；紧急处置仍须按已批准应急机制保留完整主体与事后证据，不得使用共享账号。

## 验收要求

- 缺少运维发起或业务确认时不能执行切换；
- 标记为安全事件时，缺少安全负责人确认不能执行；
- 重复、过期或已拒绝确认不能被重放；
- 切换及回切的授权链、执行结果和业务验证永久可追溯。
