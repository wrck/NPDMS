# ADR-0015：生产恢复与灾备演练频率

## 状态

Accepted（演练频率已批准，实际演练证据待提交）

## 日期

2026-08-13

## 决策

- 每季度至少进行一次隔离恢复演练，策略代码`ISOLATED_RESTORE_QUARTERLY`。
- 每年至少进行一次完整同城温备切换演练，策略代码`METRO_WARM_SWITCH_ANNUALLY`。
- 演练须覆盖ADR-0005的RPO/RTO、ADR-0012的备份层级及ADR-0013的同城温备路径。
- 演练失败、差异、整改和复验不得覆盖原报告。

## 验收要求

- 连续12个月内至少有4次季度隔离恢复和1次完整温备切换证据；
- 恢复后业务探针、权限、文件哈希、审计、事件和外部对账通过；
- 实际RPO≤1小时、RTO≤4小时；未达标必须登记整改并复验。
