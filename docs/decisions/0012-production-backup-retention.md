# ADR-0012：生产备份分层保留策略

## 状态

Accepted（业务保留策略已批准，生产作业与恢复证据待提交）

## 日期

2026-08-13

## 决策

- 每日备份保留35天，策略代码`BACKUP_DAILY_P35D`。
- 月度备份保留13个月，策略代码`BACKUP_MONTHLY_P13M`。
- 年度备份保留7年，策略代码`BACKUP_YEARLY_P7Y`。
- 数据库连续日志或等价增量机制必须支持ADR-0005批准的RPO不超过1小时。
- 备份范围覆盖MySQL业务数据、文件内容与元数据、配置和密钥引用；实际介质、频率、加密和恢复顺序由DBA/运维在P3-E03登记。

## 边界

- 备份用于灾难恢复，不替代ADR-0006规定的永久业务数据及审计归档。
- 备份到期清理不得触发生产业务事实或永久归档删除。
- P3-E03保持`OPEN`，直至隔离恢复演练达到RPO/RTO并通过业务探针。

## 验收要求

- 调度、介质生命周期和备份目录可证明35天/13个月/7年的分层策略；
- 连续日志不存在超过1小时且无受控说明的缺口；
- 从日、月、年三个层级分别抽样恢复，业务数据、文件哈希、权限和审计一致；
- 到期清理有清单、有审计，且不影响永久业务数据。
