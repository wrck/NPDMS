# ADR-0005：生产恢复目标

## 状态

Accepted（业务目标已批准，恢复方案与演练证据待提交）

## 日期

2026-08-13

## 适用范围

NPDMS生产环境中的MySQL业务数据、文件内容与元数据、配置及密钥引用，以及恢复后重新构建的必要缓存状态。

## 决策

- 批准RPO：不超过1小时（ISO 8601：`PT1H`）。
- 批准RTO：不超过4小时（ISO 8601：`PT4H`）。
- 目标由业务侧批准；DBA和运维据此设计备份、保留、恢复顺序和隔离恢复演练。

## 边界

- 本决策只确认业务目标，不证明备份设施、恢复流程或演练已经通过。
- P3-E03继续保持`OPEN`，直至实际RPO/RTO均达到批准目标，业务探针通过，并由独立复核人确认。
- 基础设施默认值不能覆盖本业务目标；无法达到时必须提交差异、风险和新的业务决策。

## 重新决策触发条件

- 核心数据范围、文件存储或部署架构发生实质变化；
- 业务连续性等级或合规要求变化；
- 恢复演练证明当前架构无法达到目标。
