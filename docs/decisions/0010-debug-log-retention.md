# ADR-0010：调试日志有限期留存

## 状态

Accepted（留存期限已批准，生产配置与执行证据待提交）

## 日期

2026-08-13

## 适用范围

为开发诊断、故障定位或专项排障临时启用的调试级日志，不包括ADR-0006永久业务审计、ADR-0007网络/安全运行日志、ADR-0008 Trace或ADR-0009指标数据。

## 决策

- 调试日志默认保存7天，策略代码`DEBUG_LOG_DEFAULT_P7D`。
- 因专项故障处理需要延长时，最长保存30天，策略代码`DEBUG_LOG_EXCEPTION_MAX_P30D`。
- 延长必须在启用前或紧急启用后最短可行时间内登记原因、负责人、适用服务/环境、开始时间和明确到期时间；到期自动恢复默认策略并清理超期数据。
- 无有效登记不得超过7天；不得通过连续续期开启事实上的长期调试日志。

## 边界

- 调试日志仍须执行脱敏、访问控制和秘密扫描，不得记录设备明文密码、私钥、Token、完整请求体或其他受限数据。
- 调试级别不得作为生产环境常态；启停、延期、查询、导出和清理均需留痕。
- 调试日志到期不得删除对应业务事实、审批历史、明确留痕操作审计或其他已批准留存类别。
- P3-E05继续保持`OPEN`，直至生产日志级别控制、延期登记、自动到期和清理证据通过复核。

## 验收要求

- 默认生命周期配置为7天；无登记的第8天样本不可继续保留；
- 合法专项登记可延长，但到期时间不得超过启用日起30天；
- 缺失原因、负责人或到期时间的延期请求被拒绝；
- 到期自动恢复日志级别并执行清理，永久审计及其他留存类别零误删；
- 调试日志秘密扫描零命中。

## 重新决策触发条件

- 安全、监管或隐私要求缩短调试数据窗口；
- 生产故障复盘证明7天无法满足常规定位；
- 日志采集架构变化导致延期控制或自动清理无法执行。
