# ADR-0007：普通网络与安全运行日志留存

## 状态

Accepted（留存期限已批准，生产设施与执行证据待提交）

## 日期

2026-08-13

## 适用范围

不属于ADR-0006永久留存范围的普通网络日志和安全运行日志，包括网关、负载均衡、网络设备、安全设施及平台安全运行产生的技术诊断记录。

## 决策

- 总留存期：1年，策略代码`NETWORK_SECURITY_LOG_P1Y`。
- 在线留存：180天，ISO 8601：`P180D`。
- 不可变冷存储：其后185天，ISO 8601：`P185D`。
- 冷存储必须具备访问控制、加密、完整性校验、生命周期执行记录和授权恢复检索能力。
- 到期清理仅适用于本决策范围内的普通技术日志，必须由受控生命周期策略执行并产生清理清单和审计记录。

## 边界

- 业务事实、审批历史，以及PRD/SDS明确要求记录、审计或留痕的操作，继续执行ADR-0006的`PERMANENT_NON_DELETABLE`，不得因本决策到期删除。
- 日志中不得保存设备明文密码、私钥、Token等秘密；脱敏和秘密扫描要求不因冷热分层降低。
- 本决策不确定普通Trace、指标聚合和调试日志的留存期限，这些类别分别确认。
- P3-E05继续保持`OPEN`，直至生产后端、生命周期、不可变冷存储、检索和到期清理证据通过复核。

## 验收要求

- 分类器能够稳定区分永久业务审计与有限期网络/安全运行日志；
- 在线180天和冷存储185天边界可由配置、对象生命周期及实际样本证明；
- 冷存储抽样恢复后时间、来源、关联标识和完整性校验一致；
- 到期清理不会命中ADR-0006永久记录，且清理清单可追溯。

## 重新决策触发条件

- 法律、监管、合同或公司安全基线要求更长留存；
- 日志分类或生产存储架构发生实质变化；
- 安全事件调查证明当前期限不足。
