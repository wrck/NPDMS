# ADR-0006：业务事实与明确留痕操作永久保留

## 状态

Accepted（业务留存边界已批准，生产存储与检索证据待提交）

## 日期

2026-08-13

## 适用范围

- 已形成的业务事实及其不可变历史；
- 审批申请、审批意见、审批结论、退回、撤回、作废和相关状态历史；
- PRD或SDS明确要求记录、审计、留痕或保留证据的操作及结果。

## 决策

- 上述记录采用策略代码`PERMANENT_NON_DELETABLE`，永久保留，不设置业务到期时间。
- 不提供业务用户、管理员、API、后台任务或生命周期策略删除、清空、覆盖或匿名替换上述记录的能力。
- 允许从在线存储迁移到冷存储，但迁移不是删除：对象关联、审批链、操作者、时间、前后状态、证据引用、完整性校验和检索能力必须保留。
- 业务修正通过追加更正、反向事实或新版本表达，不覆盖或删除原记录。

## 边界

- 本决策不等同于所有技术Telemetry永久保留。普通运行日志、指标、Trace和调试日志的有限留存期限另行确认。
- 永久记录中不得保存设备明文密码、私钥、Token等秘密；应保存脱敏标识、引用、摘要和访问结果。
- P3-E05继续保持`OPEN`，直至生产后端、访问控制、防篡改、冷热分层、检索恢复和删除阻断证据通过复核。

## 验收要求

- 业务界面、管理接口、批处理和存储生命周期均无法删除永久记录；
- 冷热迁移前后记录数量、业务关联、审批链和完整性校验一致；
- 冷存储记录可按授权恢复查询，查询与导出自身留痕；
- 对原事实的更正不改变原记录，仅形成可关联的新事实。

## 重新决策触发条件

- 法律、监管或司法要求与本决策发生强制冲突；
- 业务事实、审批或明确留痕操作的分类边界发生变化；
- 存储架构变化导致原有完整性或检索能力无法维持。
