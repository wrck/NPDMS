# ADR-0014：业务数据按权限导出

## 状态

Accepted

## 日期

2026-08-13

## 决策

- 导出统一建模为`ExportTask/ExportAudit`，不得为文件到期清理另建一套重复审计对象。
- 业务数据只要用户同时具备对应导出功能权限和目标数据范围权限，即可导出，不增加独立审批节点。
- 导出查询复用服务端实时授权，不得信任前端传入范围，不得扩大项目树、组织、设备、文件、凭证或字段权限。
- 敏感字段继续按字段权限脱敏；设备明文密码、私钥、Token等秘密在任何导出中均不可出现。
- 导出申请、范围快照、条件、字段、结果数量、文件引用、生成成功、失败、拒绝、操作者、时间、下载和到期清理结果永久留痕；导出留痕按ADR-0006不可删除。
- 大批量导出采用异步任务和受控文件；文件访问绑定原授权主体并在下载时重新校验权限。

## 生命周期

`已申请 → 生成中 → 生成成功/生成失败/已拒绝 → 已下载（可多次）→ 文件已过期清理`

文件清理只推进关联文件状态，不删除或终止`ExportTask/ExportAudit`永久记录。

## 边界

- 本决策批准“有权即可导出”，不批准跨越数据范围、字段范围或秘密边界。
- 不因数据属于永久业务事实或审批历史而禁止导出；是否可导出取决于功能权限、数据范围和字段权限。
- 导出成功仅表示文件已按授权生成，不代表通知送达或接收人已下载。

## 验收要求

- 有导出权限且在数据范围内的用户可完成导出，无额外审批；
- 缺少导出功能权限、越出数据范围或无字段权限时拒绝或脱敏，不泄露对象存在性；
- 权限在文件生成后被撤销时，后续下载被拒绝；
- 导出及下载记录完整、永久保留，导出内容秘密扫描零命中。
