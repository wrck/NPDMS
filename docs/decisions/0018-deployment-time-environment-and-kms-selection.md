# ADR-0018：生产环境与KMS在部署阶段实例化

## 状态

Accepted

## 日期

2026-08-13

## 决策

- 生产入口、域名、证书、网络区域和实际运维Owner在部署阶段针对目标环境指定。
- 具体KMS/Secrets Manager产品、实例、访问主体、密钥版本和运维Owner在部署阶段指定。
- P3-E01与P3-E04不再作为当前SDS Phase 3逻辑设计基线阻断项；当前阶段只冻结网络信任边界、秘密管理接口、配置契约、禁止降级规则和验收标准。
- P3-E01继续阻断目标环境部署与生产发布；P3-E04继续阻断设备凭证能力部署与生产发布。缺少部署证据时不得用开发环境、配置占位符或明文密钥替代。

同一“最晚安全门禁”原则适用于其余运行证据：实际数据服务、恢复演练、Telemetry后端和性能实测分别在部署、专项验收或生产发布前关闭。P3-E09若涉及表、字段和约束裁决，会改变数据模型并产生明显返工，因此前置到SDS数据模型基线；实际迁移执行证据仍在迁移实施与切换前关闭。

## 验收要求

- SDS不绑定具体厂商、域名或实例，但接口、配置项、安全边界和失败行为完整；
- 部署前必须提交目标环境拓扑、TLS、网络流向和Owner证据；
- 启用设备凭证能力前必须提交实际KMS、访问控制、轮换、吊销、审计和故障注入证据；
- 发布门禁可阻断缺少P3-E01/P3-E04证据的环境，但不反向阻断逻辑SDS基线。
