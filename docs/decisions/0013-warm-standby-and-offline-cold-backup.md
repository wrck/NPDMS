# ADR-0013：同城温备与离线冷备灾备形态

## 状态

Accepted（灾备形态已批准，生产拓扑与演练证据待提交）

## 日期

2026-08-13

## 决策

- 采用同城温备作为主要灾备形态，策略代码`METRO_WARM_STANDBY`。
- 温备必须支持在4小时内完成资源启动、数据恢复、依赖切换和业务验证，以满足ADR-0005的RTO。
- 另保留离线冷备作为极端灾难兜底，策略代码`OFFLINE_COLD_BACKUP_FALLBACK`。
- 具体网络、计算、数据库、对象存储、密钥设施和DAC依赖拓扑由技术架构、DBA、运维和安全Owner在P3-E01/P3-E03登记。

## 边界

- “温备”不等于已经达到RTO；必须由端到端演练证明。
- 离线冷备不是日常4小时恢复路径，不得用冷备作业成功替代温备切换验证。
- P3-E01与P3-E03保持`OPEN`，直至拓扑和恢复演练证据通过复核。

## 验收要求

- 隔离演练覆盖资源启动、数据/文件恢复、配置与密钥引用、外部依赖切换和业务探针；
- 实际RTO不超过4小时，实际RPO不超过1小时；
- 离线冷备可读取、可校验、可恢复，不依赖生产账号或单一在线设施；
- 演练失败、差异和整改均保留证据。
