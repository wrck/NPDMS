# ADR-0009：指标数据分层留存

## 状态

Accepted（留存期限已批准，生产聚合与存储证据待提交）

## 日期

2026-08-13

## 适用范围

平台、基础设施、外部集成和业务运行产生的时序指标及其5分钟/小时级聚合数据，不包括ADR-0006规定的永久业务事实、审批历史和明确留痕操作审计。

## 决策

- 原始高精度指标保存90天，策略代码`METRIC_RAW_P90D`。
- 5分钟级和小时级聚合指标保存13个月，策略代码`METRIC_AGGREGATE_P13M`。
- 聚合结果必须保留指标名称、时间窗口、聚合方法、维度口径、来源环境和版本，能够解释长期趋势与发布前后差异。
- 原始指标到期清理或下采样不得删除、改写或替代ADR-0006范围内的永久业务事实与审计记录。

## 边界

- 指标标签不得包含设备明文密码、私钥、Token、用户输入原文或其他秘密；高基数字段不得作为普通标签。
- 本决策不把聚合指标作为业务事实的权威来源；业务结果仍以领域数据和永久审计为准。
- P3-E05继续保持`OPEN`，直至生产聚合任务、存储生命周期、口径版本和查询证据通过复核。

## 验收要求

- 原始指标90天边界及5分钟/小时聚合13个月边界可由配置和样本证明；
- 聚合值可用同一时间窗原始样本重算并在批准误差范围内一致；
- 到期清理不影响长期聚合查询，也不命中永久业务事实和审计；
- 指标口径或标签变化保留版本，历史趋势不被静默重算覆盖。

## 重新决策触发条件

- 容量、成本或查询性能证明当前分层不可持续；
- NFR、审计、监管或经营分析需要更长的高精度窗口；
- 指标口径、聚合引擎或生产存储架构发生实质变化。
