# ADR-0008：分布式Trace分层留存

## 状态

Accepted（留存期限已批准，生产采样与存储证据待提交）

## 日期

2026-08-13

## 适用范围

平台、基础设施和外部集成链路产生的分布式Trace及Span，不包括ADR-0006规定的永久业务事实、审批历史和明确留痕操作审计。

## 决策

- 普通Trace保存90天，策略代码`TRACE_STANDARD_P90D`：在线30天（`P30D`），随后冷存储60天（`P60D`）。
- 错误及高风险Trace保存180天，策略代码`TRACE_ERROR_HIGH_RISK_P180D`：在线30天（`P30D`），随后冷存储150天（`P150D`）。
- 错误/高风险分类至少覆盖执行错误、凭证安全、高风险权限拒绝、审计写入失败、发布迁移失败及安全事件关联Trace。
- Trace到期仅清理诊断链路数据；对应的永久业务审计记录、业务关联标识和证据引用继续按ADR-0006保留。

## 边界

- Trace不得保存设备明文密码、私钥、Token或未脱敏业务载荷。
- 采样策略不得导致错误、高风险或发布迁移链路在批准期限内无可用证据。
- P3-E05继续保持`OPEN`，直至生产采样、分类、冷热生命周期、检索及到期清理证据通过复核。

## 验收要求

- 普通与错误/高风险Trace分类规则可测试、可追溯；
- 生命周期配置分别满足90天和180天，冷热边界符合本决策；
- 冷存储抽样恢复后traceId、span关系、时间和完整性校验一致；
- Trace清理后，关联永久审计仍可查询并能说明诊断数据已按策略到期。

## 重新决策触发条件

- 故障调查、安全响应或合规要求需要更长Trace窗口；
- Trace采样、存储成本或生产架构发生实质变化；
- 分类规则无法稳定识别错误或高风险链路。
