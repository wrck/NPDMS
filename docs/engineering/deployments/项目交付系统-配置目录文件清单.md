# 项目交付系统｜服务部署目录要求

> 适用范围：Ubuntu Server 22.04 LTS，4 台主机（前端 ×2、后端 ×1、数据库 ×1）

## 一、部署目录总表

| 主机 | 服务 | 数据目录 | 所在分区 |
| --- | --- | --- | --- |
| 前端 01/02 | Nginx | 无（不落地数据） | `/` |
| 后端 | Spring Boot | 日志 `/var/log/sdp` | `/`、`/data` |
| 后端 | Redis | `/data/redis` | `/data` |
| 后端 | MinIO | `/data/minio` | `/data` |
| 数据库 | MySQL | `/data/mysql`（datadir，含 binlog） | `/data` |

## 二、三条部署规则

| 规则 | 说明 |
| --- | --- |
| 程序放根分区 | JAR、静态包、配置等可重建内容放 `/` 下标准路径，便于版本管理与回滚 |
| 数据放 `/data` | 数据库文件、对象数据、持久化文件、上传文件统一放 `/data`，只备份这一块 |
| 日志留 `/var/log` | 日志属临时数据，不进 `/data`，配 logrotate 防写满根分区 |

## 三、必须注意的两点

| 服务 | 注意项 |
| --- | --- |
| MySQL | `datadir` 改到 `/data/mysql` |
| MinIO / Redis | 两者共用后端机 `/data`，建议拆成 `/data/minio` 与 `/data/redis`                             |
