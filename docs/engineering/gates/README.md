# 工程门禁与审查证据

本目录保存工程链各阶段的门禁状态、独立评审结论、评审输入和历史证据。它是过程治理区，不是业务需求或系统详细设计的替代物。

## 目录规则

- `phase-1/`、`phase-2/`、`phase-3/`：按工程阶段隔离门禁证据。
- 各阶段的 `gate-status.md`：该阶段唯一的当前门禁汇总，记录状态、阻塞项、签署人和复审入口。
- `input/`：外部或上游提交的评审材料，保留原始内容，默认只读，不在原文件上修改。
- `archive/`：已失效、已替代或仅供历史追溯的审查材料，不能作为当前放行依据。

## 权威性边界

1. 业务语义以 PRD 基线为准，系统设计以 `docs/design/` 为准。
2. 本目录中的评审意见只有在被确认并回写到正式 SDS、决策记录或当前 `gate-status.md` 后，才对工程链产生执行效力。
3. 任何审查稿、输入稿或历史稿都不能单独改变需求范围、数据归属、接口契约或状态机。
4. 阶段状态为 `NOT_READY` 或存在未关闭硬门禁时，不得进入下一阶段。

当前 Phase 1 入口见 [`phase-1/README.md`](phase-1/README.md)。
