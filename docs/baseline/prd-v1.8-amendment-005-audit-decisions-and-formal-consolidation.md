## 3. 正式修订边界

1. 核心内部业务角色统一为12类。“服务经理”按办事处级/一级和本地实施级/二级的项目责任语境解释，不再建立两个独立RBAC角色；相关职责、权限矩阵、数据隔离与计数同步统一。
2. 权限、状态、数据口径、异常路径、引用关系、术语和验收表达按59项裁决完成一致化；审核报告中的过程性批注、裁决提示和章节审核记录不进入正式PRD。PRD用于标识V3范围的`【建议】`属于正式范围分类，不在清理之列。
3. `SUB-01`的邮件服务引用统一指向`INT-01`；`SUB-02`的邮件通道指向`INT-10`、钉钉待办通道指向`INT-05`。
4. 资产当前视图不承诺尚无权威事实来源的服务时长和工程师上门频率；相关经营分析方向仍按V3范围管理。
5. 本修订不新增或删除正式Requirement，数量保持100项（V1 53、V2 47）；31项已编号V3、2项跨需求演进方向、9项`OUT_OF_SCOPE`及13个领域Owner均保持不变。
6. 本修订不直接新增API、数据库表、迁移、审批节点或实现任务。既有SDS、Feature、API、数据模型和测试中命中修订语义的内容必须差量复核，不得把PRD重基线化解释为下游已自动同步。
