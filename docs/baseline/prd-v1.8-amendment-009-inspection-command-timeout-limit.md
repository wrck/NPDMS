## 1. 权威来源

- 前置正式底稿：PRD V1.8修订008。
- 独立裁决：INS-02、INS-09及NFR-02正文与验收多处共同要求在线巡检单命令超时不超过30秒；NFR-02中“经审批更长”缺少审批主体、上限、作用域和验收契约。
- 工程约束：不得由SDS、Feature、代码或测试臆造审批角色、节点、阈值或状态。

## 2. 批准结论

1. V2在线巡检单命令默认超时30秒，管理员只可按已发布巡检规则配置1～30秒的正整数阈值。
2. 超过30秒的配置必须拒绝，不进入当前SDS、Feature、实现或验收。
3. 超时只终止并标记当前命令；后续命令是否继续由任务冻结的已发布巡检规则决定并留痕。
4. 删除NFR-02中“经审批更长”的孤立表述，不新增角色、审批流、状态、数据对象、Requirement或外部集成。
5. 未来确需超过30秒时，必须通过新的PRD变更补齐安全上限、审批主体、适用范围和验收契约后重新基线化。

## 3. 影响边界

- 直接影响：INS-02、INS-03、INS-09、NFR-02及其SDS、Feature和测试边界。
- 不影响：V1设备凭证与采集安全基线、INT-12采集平台内部实现、巡检任务其他状态、报告和问题闭环。
- 本修订不改变Requirement数量、优先级、目标版本、领域Owner或巡检九状态主流程。
