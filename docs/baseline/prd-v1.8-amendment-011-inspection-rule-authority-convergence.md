# PRD V1.8修订011：巡检规则权威语义收口

> 变更编号：`CHG-PRD-2026-09-02-011`<br>
> 状态：`APPROVED / MERGED_INTO_BASELINE`<br>
> 影响Requirement：`EQP-01`、`INS-02`、`INS-03`、`INS-09`、`NFR-02`<br>
> 来源裁决：`feat-inspection-feature-xkjuCC`中的修订009～012，按master现有修订009/010之后重新编号并合并承接

## 1. 决议

1. V2在线巡检单命令默认30秒，只允许配置1～30秒正整数；不建设未定义的超30秒审批分支。
2. 适用产品类型只消费AST设备产品类型受控副本公开契约。Inspection保存稳定编码与发布名称快照，不维护第二套产品类型库，不实现CRM/MES连接器。
3. 预期结果正则固定使用JDK 25 `java.util.regex.Pattern`受限子集，并由SDS冻结复杂度预算和禁止结构；不承诺PCRE兼容。
4. 规则名称归属规则稳定身份并在租户内永久唯一；停用、软删除和新revision不释放名称，历史revision不可改名。
5. 草稿除检测ID和规则名称外允许暂不完整；发布必须完成八字段、命令、`NUMBER`阈值、产品类型和安全审核校验。安全审核结论只允许`PASSED/REJECTED`。

## 2. 不变范围

- 不新增正式Requirement、角色、审批节点、规则执行状态或共享规则库版本。
- 不修改Yudao基础平台，不实现第三方连接器，不把AST产品类型复制成Inspection主数据。
- 旧`pms_srv_rule`、旧接口和旧页面继续保留；只有可证明字段可前向迁移，新能力不得建立在旧载体上。
- `Q-FINS001-005/006`继续阻断安全审核生效选择、生产审核入口和完整发布放行，本修订不代替后续业务/安全裁决。
