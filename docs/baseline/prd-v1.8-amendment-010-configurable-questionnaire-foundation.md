# PRD V1.8修订010：可配置问卷基础能力

> 修订编号：`CHG-PRD-2026-08-30-010`<br>
> 确认日期：2026-08-30<br>
> 状态：`PROPOSED_FOR_INDEPENDENT_REVIEW`<br>
> 前置基线：`CHG-PRD-2026-08-29-009`

## 1. 权威来源

- 需求方确认：ACC-02应识别并实现问卷调查的基础配置能力，不在方案阶段预设某张问卷的具体题目、答案、分值、权重、阈值或通过规则。
- 适用对象：ACC-02@V1的模板修订、问卷实例、客户答卷、服务端评分与达标判定；ACC-04仅继续消费有效达标Result。

## 2. 确认结论

1. 问卷模板修订配置题目顺序、稳定题目编码、题型、必答、答案Schema、分值映射、可选权重、计分策略、分数量纲、精度、舍入方式、阈值和适用时点；具体业务取值全部来自配置，不采用内置满意度默认值。
2. 题型与计分策略来自平台发布的受控目录；V1只执行经实现并验证的受控策略，不执行任意脚本或表达式。具体受控类型、策略代码和确定性算法由下一SDS Gate锁定。
3. 模板发布前必须验证配置完整、可判定且互相一致；未知类型/策略、重复稳定编码、无效分值/权重/阈值、缺少必要答案Schema或不能确定性计分时不得发布，也不得用技术默认值补齐。
4. 问卷实例冻结完整发布配置。客户只提交稳定题目编码及答案，客户端不得提交或覆盖总分、阈值、计分规则或达标结论；服务端按冻结配置产生唯一评分与判定。
5. 答卷结构错误、未知题目/选项或重复作答在Response写入前拒绝；结构合法但缺少必答项时保存不可变Response并形成未通过Result，保持PRD既有失败判定与历史不覆盖语义。
6. 受管种子仅作为一组可配置示例和验收输入，不构成业务默认规则；正式模板必须通过管理入口配置并发布。

## 3. 影响边界

- 直接影响：ACC-02正文以及下游ADR/SDS、Feature、Technical Plan、模板/问卷JSON契约、受管示例数据、评分服务和验收。
- 本修订不增加第三方问卷平台、任意公式引擎、V2自动触达、CLO/SUB消费者、角色—权限映射或ACC-04其他来源。
- 本修订不预先批准具体题型目录、计分策略代码、JSON字段名、数据库差量或产品实现；这些必须按工程链在下一Gate形成可执行契约。
- 本修订不改变正式Requirement数量、优先级、目标版本、领域Owner或Yudao基础平台。

## 4. 基线关系

本修订候选合并至`需求/PRD-项目实施交付管理平台.md`，并同步冻结为`docs/baseline/prd-v1.8.md`。两份文件必须保持字节一致；ACC领域投影必须由同一PRD重新生成。独立审批GO前，本修订不得回写为正式基线，也不得恢复评分实现。
