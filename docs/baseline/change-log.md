## V1.6生效后的变更规则

正式基线生效后，新增、删除、版本调整、Owner调整、权限边界调整、状态语义调整或恢复`OUT_OF_SCOPE`能力，必须通过CHG-01记录：

```text
变更申请 → 影响分析 → 业务/架构批准 → PRD与领域规格更新
→ 迁移矩阵和验收追溯更新 → 重新生成快照与校验 → 发布新基线
```
