# PRD V1.8批准修订002：组织主数据与资产地点模型

> 修订编号：`CHG-PRD-2026-08-23-002`
> 状态：`APPROVED`
> 日期：2026-08-23
> 需求方结论：公司与部门分离；办事处属于部门；地址、站点和安装位置由AST统一拥有
> 影响Requirement：`PM-01`、`PM-08`、`EXE-02`、`EQP-01`、`CUS-01`、`INT-09`

## 1. 变更原因

PRD V1.8已有公司、部门、办事处、实施地点、客户地址和设备安装位置语义，但未给出统一主数据承载方式。现有下游设计和实现仍存在自由文本地点、数值办事处ID、客户地址与设备安装位置混用等情况，无法可靠支持多站点项目、工勘/安装维护地点、设备迁移历史和服务经理人工指派。

## 2. 批准后的组织规则

1. 公司和部门是两个独立主数据对象；办事处是组织架构中的部门，不建立独立办事处主数据。
2. 部门主数据的统一编码字段为`system_dept.code`。跨模块关系和快照统一使用`department_id/department_code/department_name`，不再引入`office_code`、`dept_no`或`office_department_code`。
3. 公司与部门不得建立全局从属推导。用户、项目或其他业务需要公司—部门范围时，必须在同一有效关系行中同时保存并校验公司和部门；仅有部门不能推导或授予跨公司权限。
4. LDAP/AD继续作为组织架构同步来源之一；平台保存稳定来源键、同步版本和最近有效主数据。来源不可用时只读使用最近成功版本，不伪造公司—部门关系。

## 3. 批准后的地点规则

1. `Address`承载国家、省、市、区县编码/名称、详细地址、完整展示地址及可空经纬度。
2. `Site`是可复用业务站点；同一地址可建立多个站点。站点可选引用客户，但不绑定公司或办事处，也不建立客户多角色关系。
3. `SiteLocation`是站点内部任意深度位置树，可表达园区、楼栋、楼层、机房、区域、机柜、U位及其他位置节点。
4. Address、Site、SiteLocation、外部来源映射和行政区划—部门映射由AST拥有；CUS只保存客户对地址/站点的稳定引用，不拥有物理地点实体。
5. 项目与站点为多对多关系；一个项目可包含多个站点，同一站点可被多个项目复用，并可指定一个当前主站点。
6. 行政区划与服务办事处使用`area_code + area_level -> department_code`精确映射。V1只用于候选过滤和提示，最终服务经理由授权人员人工确认；缺失、停用或无效映射不阻断项目创建。
7. 工勘和安装可在项目授权范围内新建或补正Address、Site和SiteLocation。已被引用的共享地点通过版本修订，不原位覆盖历史业务快照。
8. EXE-02确认的安装、迁移或拆除记录是设备当前位置变化的权威业务事实；完成前不更新设备当前位置。AST保存设备当前结构化位置引用和版本历史。

## 4. 字段与降级规则

1. 行政区划映射字段统一为`area_code/area_level`；不使用`administrative_division_code`。
2. 当站点尚未维护时，项目、工勘、安装和设备档案可保留原文本位置作为受控降级，并标记`location_resolution_status=UNRESOLVED`。
3. 存在有效`site_id/site_location_id`时，结构化引用为唯一权威，文本只作来源展示或历史输入；解析状态为`RESOLVED`。
4. 未解析文本不得参与自动办事处解析、自动服务经理指派、正式站点统计或结构化数据权限判断。UI必须显示“待维护”。
5. 当前为0→1建设，不迁移生产历史位置；开发和测试数据按新模型重建。兼容文本字段保留，作为站点未维护时的降级策略。

## 5. 影响分析

- Requirement数量、Owner、版本和优先级不变。
- AST增加地点聚合与公开位置契约，但不新增独立Location Context或模块。
- CUS客户地址语义调整为对AST Address/Site的引用；客户核心字段仍遵循CRM权威边界。
- PROJ拥有项目—站点关系；IMP拥有工勘、安装及位置生效事实；模块间不得直接访问AST的DO、Mapper、Repository或业务表。
- 不新增服务经理自动指派能力；PM-08 V2自动化范围不提前实现。

## 6. 权威关系

`docs/baseline/prd-v1.8.md`继续保留为不可变V1.8快照。本文件是经需求方批准的正式增量；当组织、办事处、实施地点、客户地址或设备安装位置的承载方式与原PRD存在未明确或冲突语义时，以本修订为准。其他PRD V1.8条款不变。
