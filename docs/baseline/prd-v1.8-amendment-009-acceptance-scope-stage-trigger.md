# PRD V1.8批准修订009：验收阶段与验收范围触发语义

> 修订编号：`CHG-PRD-2026-08-29-009`<br>
> 批准日期：2026-08-29<br>
> 状态：`APPROVED`<br>
> 前置基线：`CHG-PRD-2026-08-29-008`

## 1. 权威来源

- 需求方确认：按项目设定阶段，项目进入验收阶段即进入验收范围。
- 适用对象：COM-01当前有效DeliveryScope分配版本与ACC-03的AcceptanceScopeBinding。

## 2. 批准结论

1. 项目进入其设定的验收阶段时，该项目当时全部当前有效DeliveryScope分配版本同步进入验收范围。
2. 项目已经处于验收阶段时，新增或调整形成的新当前分配版本在生效时同步进入验收范围，不能通过“先进入阶段、后新增范围”绕过验收锁定。
3. 每条验收范围绑定保存精确DeliveryScope标识及分配版本；任一范围锁定、版本校验或绑定失败时，项目阶段进入或范围版本生效整体不成功，不保留部分绑定。
4. 不得把既有验收单的提交、审批、报告或项目级验收状态反推为历史AcceptanceScopeBinding。
5. 项目退出或回退验收阶段时是否关闭既有绑定，不在本次确认范围；在获得正式业务规则前不得自动解锁或关闭绑定。

## 3. 影响边界

- 直接影响：COM-01、ACC-03正文及其下游SDS、Feature、API、状态、并发、数据和验收设计。
- 下游必须锁定项目阶段Owner如何在同一业务动作中调用COM范围锁并由ACC追加绑定；不得继续把旧`submitAcceptance`状态当作触发事实。
- 本修订不批准F-COM-001 Feature Ready、Technical Plan、产品代码、Flyway、历史生产迁移、SIT、UAT或Release。
- 本修订不改变正式Requirement数量、优先级、目标版本、项目阶段定义、领域Owner或Yudao基础平台。
