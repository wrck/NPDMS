# PRD V1.8批准修订004：文件病毒扫描作为可选部署能力

> 修订编号：`CHG-PRD-2026-08-27-004`
> 状态：`APPROVED`
> 日期：2026-08-27
> 需求方结论：文件安全扫描默认关闭；关闭时不执行病毒校验并真实记录`SKIPPED`，开启时继续失败关闭
> 影响Requirement：`PLT-02`；关联`NFR-01`

## 1. 变更原因

PLT-02现行实现把ClamAV作为本地基础设施常驻加载，并要求每个FileVersion只有在病毒扫描`PASSED`后才能提交。需求方确认安全扫描属于按部署环境启用的可选能力：未启用安全扫描的环境不应加载ClamAV，也不应因缺少扫描Provider阻断普通文件上传。

## 2. 批准后的业务规则

1. 文件安全扫描由平台级部署配置统一控制，默认关闭；不是普通业务用户、租户或文件用途可自行降低的运行时规则。
2. 安全扫描关闭时，平台不调用任何病毒扫描Provider，仍必须完成服务端实际大小、SHA-256、扩展名、声明MIME、内容嗅探类型和文件策略校验；这些校验失败仍拒绝创建可引用FileVersion。
3. 安全扫描关闭且其他校验通过时，FileVersion真实记录`scanStatus=SKIPPED`，扫描Provider编码和版本为空。`SKIPPED`只表示未执行病毒扫描，不得解释或展示为“扫描通过”“安全”或`PASSED`。
4. 安全扫描开启时，平台必须使用已配置的唯一安全扫描Provider。Provider缺失、重复、不可用、超时、异常、返回`ERROR`或未知结果时完成上传失败关闭；返回`REJECTED`时拒绝入库和业务引用。
5. 同一部署实例的扫描开关变更只影响变更后新提交的FileVersion。既有不可变FileVersion保留原`PASSED`或`SKIPPED`事实，不回填、不重写、不据后续开关推导历史扫描结果。
6. 上传、版本、审计和文件事件必须携带真实扫描状态。任何关闭路径不得通过默认值、历史成功结果或兼容逻辑伪造`PASSED`。

## 3. 部署和产品边界

1. ClamAV是安全扫描开启时的当前Provider实现，不是默认必须启动的基础设施；默认部署不创建、不加载该服务。
2. 生产、受监管或业务明确要求病毒扫描的环境，由部署Owner显式启用扫描开关并提供可用Provider；启用后不允许自动降级为`SKIPPED`。
3. 本修订不新增文件状态机、业务审批节点、角色、公开上传API、文件用途或内容处置流程，不改变大小、摘要、类型、权限、不可变版本和对象存储规则。

## 4. 业务验收标准

- **WHEN** 部署未启用文件安全扫描且用户上传满足大小、摘要、类型、策略和权限要求的文件
- **THEN** 平台不调用病毒扫描Provider，创建可引用FileVersion并记录`scanStatus=SKIPPED`，Provider编码和版本为空
- **AND** 页面、API、审计和事件不得把该版本表示为扫描通过或安全
- **WHEN** 部署启用文件安全扫描且Provider返回`PASSED`
- **THEN** 平台按既有规则创建FileVersion并记录真实Provider信息
- **WHEN** 部署启用文件安全扫描但Provider缺失、重复、不可用、异常、返回`ERROR/REJECTED`或未知结果
- **THEN** 平台不创建FileVersion、FileReference或成功审计/事件，也不得自动降级为`SKIPPED`
- **WHEN** 扫描开关在既有FileVersion创建后发生变化
- **THEN** 历史版本的扫描状态、Provider事实、内容、摘要和业务引用保持不变

## 5. 权威关系

`docs/baseline/prd-v1.8.md`继续作为不可变快照。本文件是需求方批准的PLT-02正式增量；仅当原PRD、SDS或Feature把病毒扫描解释为所有部署的强制前置时，以本修订为准。病毒检测实际返回失败时仍按原规则拒绝入库，其他V1.8条款不变。
