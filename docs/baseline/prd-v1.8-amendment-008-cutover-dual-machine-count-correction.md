## 1. 权威来源

- 前置正式底稿：PRD V1.8修订007。
- 需求方裁决：五类双机部署规范性检查按明细分别为VSM双机17项、静默双机25项、DRP双机23项、普通双机24项、集群8项，合计97项。
- XLSX/HTML仅可用于名称、字段和界面实现参考，不参与数量、业务规则、不一致或验收裁决。

## 2. 批准结论

1. 五类双机部署规范性检查的发布与验收基准固定为`17 + 25 + 23 + 24 + 8 = 97`项。
2. 原“124行”不再作为CUT-07或CUT-09的发布校验、完成状态或验收数量。
3. 不把“124”解释为风险矩阵、调研矩阵或其他内容的组合总数；其历史形成原因不产生当前业务规则。
4. CUT-09仍须覆盖PRD正式列出的25+项风险配置义务；CUT-10仍须覆盖12类核心调研内容，两者与97项双机检查分别校验。
5. 本修订不改变Requirement数量、优先级、目标版本、领域Owner、CUT-07/09/10首批配置基础边界、状态机、权限或运行时流程。

## 3. 影响边界

- 直接影响：CUT-03、CUT-07、CUT-09正文中所有当前双机检查数量表述及对应Feature发布校验。
- 不影响：CUT-01～CUT-06运行态、CUT-08 V2集成、V2自动指派及任何外部系统契约。
- 历史修订记录中的V0.4“124行”保留为当时原始表述，仅用于版本追溯，不作为当前基线规则。
