# 附录C：角色与数据权限矩阵

## 1. 权限维度

- 功能权限：菜单、页面、按钮和API动作。
- 数据权限：组织、区域、项目组合、项目层级、项目成员、任务归属和对象创建人。
- 字段权限：敏感字段的可见、脱敏、编辑和导出。
- 流程权限：发起、审批、转办、加签、撤回、终止和重开。

## 3. 层级继承

- 上级项目授权可向后代项目继承；节点可追加更窄的授权。
- 下级节点不得通过本地授权扩大超出上级项目和组织边界的数据范围。
- 子树移动后必须重新计算继承权限并清理相关缓存。
- 外协和客户账号只能访问明确授权的项目、任务、文件和表单。
