# Device Ops 统一界面实施计划

2026-09-08，按已批准设计实施。风格为克制的工业运维控制台：浅色控制、深色输出与请求证据，不新增区域。

## 范围与边界
- 仅前端、文档和测试；不修改后端、数据或 API，不访问 48181 或设备，不提交、不清理已有工作区变更。
- 保留 workbench / standalone 分支、850px 短屏 42rem / 高屏 flex、两层输出 tabs 前置、摘要折叠及完整 script.content 请求快照。
- 正文 14px、辅助 12–13px、标题 14–16px；中文无衬线、命令等宽；间距采用 4/8/12/16/24px。不得通过缩小字号或隐藏溢出来压缩界面。

## 实施顺序（先红后绿）
1. 添加 locale、可选面板 eyebrow、共享状态映射和本地时间格式测试，运行并确认失败。
2. App.vue 配置 Element Plus zhCn；统一 main/management CSS 和 AppShell tokens；紧凑 PanelHeader，移除重复英文眉题及工作台重复说明，保留安全警告。
3. 管理标签中文化（命名空间、发布版本、运行环境、工作节点、权限范围、标识）；共享状态映射保留未知 fallback，筛选提交原 enum；统一本地时区显示，缺失时间不伪造；保留本页筛选提示和完整 ID。
4. 更新中文测试定位，不弱化业务断言；执行 pnpm test、pnpm ts:check、pnpm lint、pnpm build、pnpm test:e2e（七项，包括 1280×720、1440×900、1024×768）。
5. 汇报真实结果及边界，由主代理最终部署并完成真实环境浏览器验真。

## 验收
- 无外部字体服务或新增库，所有变更 LF。
- 既有证据、安全、业务操作和布局回归测试全部保留。
- 单元测试覆盖缺失/无效时间、当地时区、已知/未知状态、中文 locale 和紧凑面板契约。
