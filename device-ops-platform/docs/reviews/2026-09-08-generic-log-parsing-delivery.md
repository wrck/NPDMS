## 使用与兼容

从device-ops-platform目录可直接执行：

```powershell
java -jar device-ops-parser-semantic/target/device-ops-parser-semantic.jar `
  --release-directory parser-releases/device-command-output-1.4.0 `
  --input parser-releases/device-command-output-1.4.0/input-real-sanitized.json `
  --output device-ops-parser-semantic/target/result-1.4.0.json
```

在线环境须按既有控制面创建草稿、验证、发布，再显式绑定/激活新的releaseId；新目录不会自动发布入库。本次没有操作运行数据库、真实设备或活动发布。旧任务重试仍使用原坐标，重新解析创建新结果。

保留旧版本行为同时意味着旧1.3已知边界不会被原地修补；新输入推荐选择1.4，不建议继续用1.3处理未经安全评估的敏感内容。

## 保留的边界与未扩展项

- 没有新增结构规则选项白名单、局部区域规则DSL、CSV/JSONL/XML解析器或任意脚本插件。
- 未标记自然语言与多词键边界仍是启发式；不能证明任意厂商/任意日志都已正确结构化。仅表头和不可靠续行保守回退文本。
- 结构预算仍在section构造后裁剪；DELIMITED_SECTION仍先生成分段。已约束事实候选对象分配并设置递归深度，但这不是无限流式解析器，输入字节/输出上限不可移除。
- 原始脱敏基线有两条凭据行的前导空格差异，本次未改旧输入；配置仍保留100段/162条子行。
- 没有改前端整体布局，也未重采设备日志或执行在线升级。
